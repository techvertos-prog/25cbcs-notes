awk: column processing and reports

awk is a small programming language built for one job: read text line by line, split each line into fields, and act on the lines that match a pattern. It replaces cut | grep | sort | uniq chains with one readable program, and it can count, sum, average and group, which is why every report in the labs (salaries per department, revenue per region, hits per IP) is written in awk.

Syntax and program structure

syntax
awk [-F SEP] [-v var=value] 'PROGRAM' [FILE...]
awk [-F SEP] [-v var=value] -f program.awk [FILE...]

# PROGRAM is a list of   pattern { action }   rules:
awk '
  BEGIN        { ... }     # runs once, before the first line is read
  /regex/      { ... }     # runs for every line matching regex
  $3 > 100     { ... }     # runs for every line where field 3 > 100
               { ... }     # no pattern: runs for EVERY line
  END          { ... }     # runs once, after the last line
' file

Either half of a rule may be missing:

  • Pattern without action: awk '$5 > 90' prints matching lines (the default action is { print }).
  • Action without pattern: awk '{ print $1 }' runs on every line.

How it works

  1. Run the BEGIN block (set separators, print headers, initialise variables).
  2. Read one record (normally one line, separated by RS) into $0.
  3. Split it into fields $1, $2 … $NF using the field separator FS (default: runs of spaces/tabs). Set NR (record number) and NF (number of fields).
  4. Test every rule's pattern in order; run the action of each rule that matches.
  5. Repeat from step 2 until input ends, then run END (print totals).
mental model
"102,Priya Sharma,Engineering,Delhi,135000,2023-02-27"     (FS=",")
   $1    $2            $3        $4     $5      $6         NF=6, $NF = $6

Variables need no declaration: an unused variable is "" as a string and 0 as a number. Strings that look like numbers are compared and added as numbers. That is why sum += $5 just works.

OptionMeaning

-v name=valuedefine a variable before BEGIN runs (repeatable), the safe way to pass shell values

#!/usr/bin/awk -f
# disk_alert.awk - report filesystems above a threshold from `df -h` output
# usage: df -h | awk -v limit=85 -f disk_alert.awk
BEGIN {
    if (limit == "") limit = 80          # default when -v limit=... is not given
    printf "%-16s %6s %6s  %s\n", "FILESYSTEM", "SIZE", "USE%", "MOUNT"
}
NR == 1 { next }                         # skip df header
{
    pct = $5 + 0
    if (pct >= limit) {
        printf "%-16s %6s %5d%%  %s\n", $1, $2, pct, $6
        bad++
    }
}
END {
    printf "%d of %d filesystems at or above %d%%\n", bad, NR - 1, limit
    exit (bad > 0)                       # exit status 1 if any alert -> usable in if
}

Use cases

Use case 1 Department salary report

Scenario: HR asks for a per-department summary of employees.csv: head count, total, average, minimum and maximum salary, the best-paid person, and a grand total line, as a neatly aligned table. One pass over the file, arrays keyed by department, and printf for layout.

awk · dept_report.awk
#!/usr/bin/awk -f
# dept_report.awk - salary statistics per department
# usage: awk -F, -f dept_report.awk employees.csv | sort ...  (see wrapper)
NR == 1 { next }                                  # skip CSV header
{
    d = $3; s = $5 + 0
    n[d]++
    sum[d] += s
    if (!(d in min) || s < min[d]) min[d] = s
    if (s > max[d]) { max[d] = s; top[d] = $2 }
    total += s; people++
}
END {
    for (d in n)
        printf "%-12s %5d %10d %10.0f %9d %9d  %s\n",
               d, n[d], sum[d], sum[d] / n[d], min[d], max[d], top[d]
    # grand total, tagged so the wrapper can print it last
    printf "TOTAL        %5d %10d %10.0f\n", people, total, total / people
}
bash · dept_report.sh
#!/usr/bin/env bash
# dept_report.sh - print a formatted department salary report
set -euo pipefail
csv="${1:-datasets/employees.csv}"
[[ -r "$csv" ]] || { echo "cannot read $csv" >&2; exit 1; }

printf '%-12s %5s %10s %10s %9s %9s  %s\n' DEPARTMENT COUNT TOTAL AVERAGE MIN MAX TOP-EARNER
printf '%.0s-' {1..80}; echo
report=$(awk -F, -f dept_report.awk "$csv")

# department rows sorted by AVERAGE (column 4), highest first
grep -v '^TOTAL' <<< "$report" | sort -k4,4nr
printf '%.0s-' {1..80}; echo
grep '^TOTAL' <<< "$report"

How it works:

  • n[d]++, sum[d] += s: one array per statistic, all keyed by department name. After one pass every array holds the per-department value.
  • !(d in min) || s < min[d]: initialises the minimum from the first salary seen for that department (testing min[d] == 0 would break if a salary were 0, and testing "" would create the element).
  • for (d in n) produces rows in random order, so the wrapper sorts by the AVERAGE column with sort -k4,4nr.
  • The grand total row starts with TOTAL, so the wrapper can keep it out of the sort with grep -v and print it last, under a rule. printf '%.0s-' {1..80} prints 80 dashes (the %.0s consumes each argument but prints nothing of it).

Use case 2 Sales pivot table: revenue by region × product

Scenario: management wants a cross-tab of sales.csv, regions as rows, products as columns, revenue (units × unit_price) in each cell, with row and column totals. This is a spreadsheet "pivot table" built with a two-dimensional awk array.

awk · pivot.awk
#!/usr/bin/awk -f
# pivot.awk - revenue pivot: rows = region ($2), columns = product ($3)
# usage: awk -F, -f pivot.awk sales.csv
function isort(a, n,    i, j, t) {               # portable in-place sort of a[1..n]
    for (i = 2; i <= n; i++)
        for (j = i; j > 1 && a[j-1] > a[j]; j--) { t = a[j]; a[j] = a[j-1]; a[j-1] = t }
}
NR == 1 { next }
{
    rev = $4 * $5
    cell[$2, $3] += rev                          # 2-D key: region SUBSEP product
    rowtot[$2]   += rev
    coltot[$3]   += rev
    grand        += rev
    if (!($2 in seenR)) { seenR[$2] = 1; R[++nr] = $2 }
    if (!($3 in seenC)) { seenC[$3] = 1; C[++nc] = $3 }
}
END {
    isort(R, nr); isort(C, nc)
    printf "%-8s", "REGION"
    for (j = 1; j <= nc; j++) printf " %10s", C[j]
    printf " %11s\n", "TOTAL"
    for (i = 1; i <= nr; i++) {
        printf "%-8s", R[i]
        for (j = 1; j <= nc; j++) printf " %10d", cell[R[i], C[j]]   # missing cell -> 0
        printf " %11d\n", rowtot[R[i]]
    }
    printf "%-8s", "TOTAL"
    for (j = 1; j <= nc; j++) printf " %10d", coltot[C[j]]
    printf " %11d\n", grand
}
bash · run it
awk -F, -f pivot.awk datasets/sales.csv
output
REGION      Headset   Keyboard     Laptop    Monitor      Mouse       TOTAL
East          52500      28500          0      48000       8800      137800
North             0      27000          0          0      48800       75800
South         35000      12000     330000      36000      12800      425800
West          56000      55500     220000     144000      29600      505100
TOTAL        143500     123000     550000     228000     100000     1144500

Key ideas:

  • cell[$2, $3]: awk joins the two subscripts with the invisible SUBSEP character, giving a single string key such as "West\034Laptop". That is how awk simulates 2-D arrays.
  • Region and product names are collected in first-seen order into the numerically indexed arrays R and C, then sorted with our own isort, so the output is identical in gawk, mawk and BSD awk (no asort needed).
  • An empty cell (North sold no Laptops) prints as 0 because an unset element used as a number is 0, but note that merely reading cell[...] creates it.

Use case 3 Web server log summary

Scenario: produce a daily summary of access.log for the ops team: total requests and bandwidth, unique visitors, status-code classes with percentages, top client IPs, the most-requested missing (404) pages, and suspicious scanners (clients whose requests are mostly 4xx).

bash · logsummary.sh
#!/usr/bin/env bash
# logsummary.sh - summarise an Apache/Nginx combined access log with awk
set -euo pipefail
log="${1:-/var/log/nginx/access.log}"
[[ -r "$log" ]] || { echo "cannot read $log" >&2; exit 1; }

echo "== Summary of $log =="
awk '
{
    req++
    bytes += $10
    ip[$1]++
    class = substr($9, 1, 1) "xx"            # 200 -> 2xx
    cls[class]++
    if ($9 >= 400) bad[$1]++
}
END {
    printf "Requests        : %d\n", req
    printf "Bandwidth       : %.2f MB\n", bytes / 1024 / 1024
    printf "Unique clients  : %d\n", length(ip)
    print  "Status classes  :"
    for (c in cls) printf "   %s %4d  %5.1f%%\n", c, cls[c], 100 * cls[c] / req | "sort"
    close("sort")                             # flush the sort pipe before continuing
    print  "Suspicious clients (>= 50% errors, >= 3 requests):"
    for (h in ip)
        if (ip[h] >= 3 && bad[h] / ip[h] >= 0.5)
            printf "   %-15s %d of %d requests failed\n", h, bad[h], ip[h]
}' "$log"

echo "Top 3 clients:"
awk '{ n[$1]++ } END { for (h in n) printf "   %4d %s\n", n[h], h }' "$log" | sort -rn | head -3

echo "Top missing pages (404):"
awk '$9 == 404 { n[$7]++ } END { for (p in n) printf "   %4d %s\n", n[p], p }' "$log" | sort -rn

bash logsummary.sh datasets/access.log

Techniques used:

  • substr($9, 1, 1) "xx": string concatenation is just writing values next to each other.
  • printf ... | "sort": awk can pipe its own output into a command. All lines printed to the same command string share one pipe; close("sort") ends it so the sorted block appears before what follows.
  • length(ip): number of distinct keys = unique visitors.
  • The ratio test bad[h] / ip[h] >= 0.5 only finds 185.220.101.3 (the sqlmap scanner), exactly the client you would block.

Viva / exam questions

What is the difference between NR and FNR?

NR counts records across all input files; FNR restarts at 1 for each file. NR == FNR is therefore true only while reading the first file.

What are BEGIN and END used for?

BEGIN runs before any input is read (set FS, print headers, initialise); END runs after all input (print totals and averages).

How do you print the last field of each line?

awk '{ print $NF }'. NF is the number of fields, so $NF is the last one; $(NF-1) is the second last.

How do you pass a shell variable into awk?

awk -v name="$var" '...', or read an exported variable via ENVIRON["var"].

What is an associative array in awk?

An array indexed by strings rather than numbers, e.g. count[$3]++. Elements are created on first use; iterate with for (k in count).

Difference between sub and gsub?

sub replaces the first match, gsub all matches. Both modify the target in place and return the number of replacements.

How do you change the output separator to a comma?

awk 'BEGIN{OFS=","} {$1=$1; print}': set OFS and rebuild the record (or print fields with commas between them).

What does awk '!seen[$0]++' do?

Prints each distinct line once, keeping first-seen order, like sort -u without sorting.

Name two gawk-only features.

asort()/asorti(), strftime(), PROCINFO["sorted_in"], gensub(), -i inplace, IGNORECASE.
