Dataset library

Every example in this wiki reads from the files in datasets/. This page describes each file: what it represents, its format and fields, which pages use it, and the full contents in a scrollable viewer. Open a terminal in the project folder and the commands on every page will give exactly the output shown.

Getting the files

The datasets ship with the wiki in the datasets/ folder next to index.html; there is nothing to download. Run all commands from the project root so the relative paths work:

bash
cd CBCS-UNIT4-STUDY-GUIDE
ls datasets/
wc -l datasets/*            # line counts
head -3 datasets/employees.csv
Recreate or copyEach viewer below has a Copy button. If you are working on a lab machine without the wiki, copy the contents and paste them into a file with a here-document, e.g. cat > employees.csv <<'EOF' … EOF (the quoted 'EOF' stops the shell from expanding $ signs). Copy the whole folder to a lab VM with scp -r datasets/ user@vm:~/. Treat these files as read-only: if an exercise edits a file (for example sed -i), work on a copy (cp datasets/app.conf /tmp/).
Safe dataAll data is fictional. Internal hosts use private ranges (10.x, 172.16.x, 192.168.x) and the documentation ranges 198.51.100.0/24 and 203.0.113.0/24; the few public attacker IPs in the logs are well-known scanner and Tor addresses used only as realistic examples. Domains are example.com, and passwords and tokens are placeholders.
