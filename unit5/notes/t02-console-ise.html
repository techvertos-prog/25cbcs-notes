Console & ISE

There are three places to work with PowerShell: the console, the old ISE editor, and VS Code.

Topic 02~15 min
Before this:F2 Install & open01 Introduction
Key idea

Use the console to type quick commands. Use an editor (VS Code, or the ISE on old setups) to write and run scripts.

The console

The console is a window with a prompt. The prompt shows the current folder.

the prompt · sample, yours will differ
PS C:\Users\aarav\unit5>
  • PS means you are in PowerShell (not CMD).
  • C:\Users\aarav\unit5 is the current folder.
  • > means "type here".
TipOn Windows, use Windows Terminal. It has tabs, easy copy/paste and can open PowerShell 7, Windows PowerShell 5.1 and CMD side by side.

Useful keys

KeyWhat it does
TabCompletes a command, parameter or file name. Press again for the next match.
↑ / ↓Previous / next command from history.
Ctrl+RSearch your command history.
Ctrl+CStop a running command (or copy, if text is selected).
EscClear the current line.
Ctrl+V or right-clickPaste.
clsClear the screen (alias of Clear-Host).
Get-HistoryList the commands you typed this session.
powershell
Get-History
output · sample, yours will differ
  Id     Duration CommandLine
  --     -------- -----------
   1        0.012 Get-Date
   2        0.031 Get-Content datasets/servers.txt
   3        0.004 cls
NoteIn Windows Terminal you can also use Ctrl+Shift+C and Ctrl+Shift+V. On macOS use Cmd+C / Cmd+V.

The ISE (old editor)

ISE = Integrated Scripting Environment. It comes with Windows and works only with Windows PowerShell 5.1.

powershell · Windows only
powershell_ise          # or search "ISE" in the Start menu
Script pane

Top. Write and save .ps1 files.

Console pane

Bottom. Shows output; you can type commands here too.

Commands add-on

Side. Search cmdlets and fill in parameters with a form.

KeyIn the ISE
F5Run the whole script.
F8Run only the selected lines.
Ctrl+SpaceShow IntelliSense suggestions.
Ctrl+JInsert a snippet (for example an if block).
Ctrl+BreakStop a running script.
Watch outThe ISE is no longer developed. It cannot run PowerShell 7 and does not exist on Linux or macOS. Learn it for the exam, but use VS Code for real work.

VS Code: the modern replacement

  1. Install Visual Studio Code (free, all platforms).
  2. Open Extensions (Ctrl+Shift+X) and install PowerShell by Microsoft.
  3. Open the unit5 folder, create hello.ps1, and press F5.
powershell
code hello.ps1          # opens (or creates) the file in VS Code

The same keys work: F5 runs the script, F8 runs the selection. Output appears in the PowerShell terminal at the bottom.

Try it

  1. Type Get-Con and press Tab. What does it complete to?
  2. Run three commands, then list them with history.
  3. Press ↑ to bring back your last command and run it again.
  4. Open VS Code, write Get-Date in a new .ps1 file, and run it with F5.
Answers
powershell
Get-Content        # Tab completes it; press Tab again to cycle other matches
Get-History        # or its alias: h

Remember

  • The prompt PS C:\...> shows the current folder.
  • Tab completes, ↑ recalls, Ctrl+C stops.
  • ISE: 5.1 only, F5 runs the script, F8 runs the selection, no longer developed.
  • VS Code with the PowerShell extension is the modern editor.
VivaWhat is the PowerShell ISE? It is the Integrated Scripting Environment that ships with Windows PowerShell 5.1. It has a script pane and a console pane; F5 runs the script and F8 runs the selected lines. It does not support PowerShell 7, so Microsoft recommends VS Code with the PowerShell extension.
