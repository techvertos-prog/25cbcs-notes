User Input

Read-Host pauses the script, shows a prompt, and waits for the user to type something.

Topic 09~15 min
Before this:06 Writing scripts08 Variables
Key idea

Read-Host always returns a string. If you need a number, convert it with [int] before doing maths.

  • Prompt
  • User types
  • String stored
  • Convert / check
  • Use it

Read-Host

powershell
$name = Read-Host "Enter your name"
"Hello, $name!"
output
Enter your name: Aarav
Hello, Aarav!

PowerShell adds the : after your prompt text by itself.

It is always a string

powershell
$age = Read-Host "Age"
$age.GetType().Name
$age + 1
output
Age: 20
String
201

"20" + 1 joins text, giving 201. Convert first:

powershell
$age = [int](Read-Host "Age")
$age + 1
output

Watch outIf the user types abc, [int] fails with an error. The loop below shows how to check first.

Passwords: -AsSecureString

powershell
$pw = Read-Host "Password" -AsSecureString
$pw
output
Password: ********
System.Security.SecureString

Typing shows *, and the value is stored encrypted in memory, so printing it shows only its type.

PowerShell 7Read-Host "PIN" -MaskInput also hides typing with *, but returns a normal string. Use it for things that are secret on screen but not truly sensitive.

A validating input loop

Keep asking until the answer is good.

powershell
do {
    $text = Read-Host "Enter marks (0-100)"
    $ok = ($text -match '^\d+$') -and ([int]$text -le 100)
    if (-not $ok) { Write-Host "Please type a number from 0 to 100." -ForegroundColor Yellow }
} until ($ok)

$marks = [int]$text
"Saved: $marks"
output
Enter marks (0-100): abc
Please type a number from 0 to 100.
Enter marks (0-100): 150
Please type a number from 0 to 100.
Enter marks (0-100): 85
Saved: 85
How it works'^\d+$' means "only digits". -and stops early if the first test fails, so [int]"abc" never runs. Loops are covered in 12 Loops.

The alternative: script parameters

Read-Host stops and waits. Parameters let the user give values on the command line, so the script can run unattended.

greet-param.ps1
param(
    [Parameter(Mandatory)]
    [string]$Name
)
"Hello, $Name!"
powershell
./greet-param.ps1 -Name Priya
./greet-param.ps1               # Mandatory, so PowerShell asks
output · sample
Hello, Priya!

Mini example: greeting

greet.ps1
# greet.ps1 : ask two questions, then answer
$name = Read-Host "What is your name"
$year = [int](Read-Host "What year were you born")
$age  = (Get-Date).Year - $year

Write-Host "----------------"
"Hello, $name!"
"You turn $age this year."
output · in 2026
What is your name: Isha
What year were you born: 2006
----------------
Hello, Isha!
You turn 20 this year.

Try it

  1. Ask for two numbers and print their sum. Check that 3 and 4 give 7, not 34.
  2. Ask for a password with -AsSecureString and print "Password received".
  3. Ask for a server name and say whether it is in datasets/servers.txt.
Answers

Remember

  • Read-Host "Prompt" shows Prompt: and returns a string.
  • Use [int] / [double] before maths.
  • -AsSecureString hides and protects passwords.
  • Validate in a loop; prefer parameters for scripts that run unattended.
