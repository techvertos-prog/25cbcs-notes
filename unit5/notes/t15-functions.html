Functions

A function is a named block of code you write once and call many times, just like a cmdlet.

Topic 15~25 min
Before this:03 Cmdlets06 Writing scripts11 if, else & switch14 Hashtables
Key idea

Inputs go in through param(). Everything the function outputs comes back to the caller, not only what follows return.

Define and call

  • function Name { … }
  • Call: Name
  • Output comes back
powershell
function Get-Greeting {
    "Hello!"
}
Get-Greeting
output
Hello!

Define the function before you call it. In a script, put functions at the top.

Parameters with param()

Give each parameter a type and, if you like, a default value.

powershell
function Get-Greeting {
    param(
        [string]$Name = 'friend'
    )
    "Hello, $Name!"
}
Get-Greeting
Get-Greeting -Name Priya
Get-Greeting Priya          # by position
output
Hello, friend!
Hello, Priya!
Hello, Priya!
powershell
function Get-Total {
    param([int]$A, [int]$B)
    $A + $B
}
Get-Total -A 5 -B 7
Get-Total 5 '7'             # '7' is converted to an int
output
12
12
Watch outCall functions like cmdlets: Get-Total 5 7. Writing Get-Total(5, 7) passes one array to $A.

Returning values

Any value that is not saved or printed with Write-Host becomes output.

powershell
function Get-Square {
    param([int]$Number)
    "Working..."                # this is output too!
    $Number * $Number
}
$result = Get-Square 4
$result
output
Working...
16

$result got both lines. Use Write-Host "Working..." for messages that should only go to the screen.

return sends a value and leaves the function straight away.

powershell
function Test-Pass {
    param([int]$Marks)
    if ($Marks -ge 40) { return 'Pass' }
    'Fail'
}
Test-Pass 72
Test-Pass 33
output
Pass
Fail

Mandatory and switch parameters

[Parameter(Mandatory)] makes PowerShell ask for a value that was not given.

powershell
function Get-Greeting {
    param(
        [Parameter(Mandatory)]
        [string]$Name
    )
    "Hello, $Name!"
}
Get-Greeting
output · you type Sneha
cmdlet Get-Greeting at command pipeline position 1
Supply values for the following parameters:
Name: Sneha
Hello, Sneha!

A [switch] is an on/off flag. It is $true only when you type it.

powershell
function Get-Greeting {
    param(
        [string]$Name = 'friend',
        [switch]$Loud
    )
    $text = "Hello, $Name!"
    if ($Loud) { $text.ToUpper() } else { $text }
}
Get-Greeting -Name Isha
Get-Greeting -Name Isha -Loud
output
Hello, Isha!
HELLO, ISHA!

Pipeline input

Add ValueFromPipeline and put the work in a process { } block. It runs once per piped item.

powershell
function Get-Double {
    param(
        [Parameter(ValueFromPipeline)]
        [int]$Number
    )
    process { $Number * 2 }
}
1..3 | Get-Double
output
2
4
6
NoteWithout process { }, only the last piped item is used.

Naming: Verb-Noun

Name functions like cmdlets: an approved verb, a dash, a singular noun. Get-Verb lists the approved verbs.

VerbUse it toExample
Getread or return dataGet-Grade
Setchange somethingSet-Theme
Newcreate somethingNew-Report
Removedelete somethingRemove-OldLog
Testreturn True/FalseTest-Pass
Showdisplay to the userShow-Menu
TipAvoid made-up verbs like Calculate- or Make-. Use Get- or New- instead.

Try it

  1. Write Get-Area with [int]$Width and [int]$Height that returns the area. Call it with 4 and 5.
  2. Give $Height a default of 1 and call Get-Area -Width 9.
  3. Write Test-Even that returns $true for even numbers.
Answers
powershell
function Get-Area {
    param([int]$Width, [int]$Height = 1)
    $Width * $Height
}
Get-Area 4 5             # 20
Get-Area -Width 9        # 9

function Test-Even {
    param([int]$Number)
    $Number % 2 -eq 0
}
Test-Even 6              # True

Remember

  • function Verb-Noun { param(...) ... }, defined before it is called.
  • Call with spaces: Get-Total 5 7 or -A 5 -B 7, never ( , ).
  • All output is returned; return also exits early.
  • [Parameter(Mandatory)] asks for a value; [switch] is a flag.
  • Pipeline input needs ValueFromPipeline and process { }.
VivaWhat does a PowerShell function return? Every value it outputs, not only the one after return. If it outputs several values, the caller receives an array. return just adds a final value and exits.
