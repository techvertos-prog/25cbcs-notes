Arrays

An array is one variable that holds a list of values, kept in order and numbered from 0.

Topic 13~20 min
Before this:08 Variables10 Operators12 Loops
Key idea

Commas make an array. Each item has an index: the first is [0], the last is [-1].

Create an array

powershell
$fruits = @('apple', 'banana', 'cherry')   # @( ) style
$nums   = 10, 20, 30, 40, 50               # commas are enough
$empty  = @()                              # empty array
$fruits
output
apple
banana
cherry
Index01234
$nums1020304050
Negative-5-4-3-2-1

Index, slice and count

powershell
$nums[0]          # first
$nums[-1]         # last
$nums[1..3]       # slice: items 1 to 3
$nums[0, 2]       # pick items 0 and 2
$nums.Count
$empty.Count
output
10
50
20
30
40
10
30
5
0
NoteAn index past the end, like $nums[10], gives nothing ($null), not an error.

Many commands return arrays. Get-Content gives one item per line.

powershell
$servers = Get-Content datasets/servers.txt
$servers.Count
$servers[1]
output
5
web02

Add items with +=

powershell
$nums += 60
$nums.Count
$nums[-1]
output
6
60
Watch outArrays have a fixed size. += builds a new copy with one more item. That is fine for small lists but slow for thousands of items.
TipFor a list that grows a lot, use a List: $list = [System.Collections.Generic.List[string]]::new(), then $list.Add('web01'). Older scripts use [System.Collections.ArrayList], whose .Add() also prints the new index, so write [void]$al.Add('x').

Loop, search and sort

powershell
foreach ($f in $fruits) {
    "I like $f"
}
output
I like apple
I like banana
I like cherry

-contains asks "is this value in the array?". -in is the same, written the other way round.

powershell
$fruits -contains 'banana'
'kiwi' -in $fruits
output
True
False
powershell
$list = 3, 1, 2, 3, 1
($list | Sort-Object) -join ' '
($list | Sort-Object -Descending) -join ' '
($list | Sort-Object -Unique) -join ' '
output
1 1 2 3 3
3 3 2 1 1
1 2 3

An array of objects

Import-Csv returns an array, one object per row.

powershell
$students = Import-Csv datasets/students.csv
$students.Count
$students[0]
output
8

Name    : Aarav
Class   : 10A
Maths   : 92
Science : 85
English : 78

$students.Name collects one property from every item.

powershell
$students.Name -join ', '
$students[-1].Maths
$students | Where-Object { [int]$_.Maths -ge 90 } | Select-Object Name, Maths
output
Aarav, Priya, Rohan, Sneha, Kabir, Isha, Vikram, Ananya
99

Name   Maths
----   -----
Aarav  92
Ananya 99
TipWrap a command in @( ) to always get an array, even for one or zero results: @(Get-Content datasets/servers.txt | Where-Object { $_ -like 'db*' }).Count gives 1.

Try it

  1. Make $colors = 'red','green','blue'. Print the last one with a negative index.
  2. Add 'yellow' and print the count.
  3. Check whether web01 is in datasets/servers.txt.
  4. From numbers.txt, show the three largest numbers.
Answers
powershell
$colors = 'red', 'green', 'blue'
$colors[-1]                                            # blue
$colors += 'yellow'; $colors.Count                     # 4
(Get-Content datasets/servers.txt) -contains 'web01'   # True
Get-Content datasets/numbers.txt | Sort-Object { [int]$_ } -Descending | Select-Object -First 3   # 45 33 28

Remember

  • Create with commas or @( ); empty is @().
  • First is [0], last is [-1], slice with [1..3].
  • .Count gives the size; -contains searches.
  • += makes a new copy; use a List for big lists.
VivaWhy is += slow on a large array? Arrays are fixed-size, so every += creates a new array and copies all the old items into it. A generic List grows in place with .Add().
