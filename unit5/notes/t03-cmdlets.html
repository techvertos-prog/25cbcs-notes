Cmdlets

A cmdlet ("command-let") is a built-in PowerShell command named in Verb-Noun form, like Get-Process.

Topic 03~20 min
Before this:F3 First commands01 Introduction02 Console & ISE
Key idea

Every cmdlet is Verb-Noun: the verb says the action, the noun says the thing. Learn a few verbs and you can guess most command names.

Verb-Noun naming

CmdletVerbNounDoes
Get-ProcessGetProcessLists running programs
Stop-ServiceStopServiceStops a service
New-ItemNewItemCreates a file or folder
Import-CsvImportCsvReads a CSV file as objects

The noun is always singular: Get-Process, never Get-Processes.

Common verbs

Get

Read or list something.

Set

Change something.

New

Create something.

Remove

Delete something.

Start / Stop

Begin or end a process or service.

Import / Export

Read from or write to a file format.

Out / Write

Send output somewhere.

Test

Check something, return True/False.

Get-Verb lists all approved verbs.

powershell
Get-Verb -Verb Get
output · PowerShell 7
Verb AliasPrefix Group  Description
---- ----------- -----  -----------
Get  g           Common Specifies an action that retrieves a resource

Parameters

Parameters start with a dash and change what a cmdlet does.

KindLooks likeMeaning
Named-Path datasetsName, then value.
PositionaldatasetsValue only; its position tells which parameter it is.
Switch-RecurseOn/off flag. No value needed.
powershell
# named parameters
Get-Content -Path datasets/servers.txt -TotalCount 2
output
web01
web02
powershell
# positional: "datasets" goes to -Path. -Name is a switch.
Get-ChildItem datasets -Filter *.csv -Name
output
inventory.csv
students.csv
TipYou can shorten a parameter name if it stays unique: -TotalCount → -Tot. Press Tab after - to cycle through parameters.

Aliases

An alias is a short nickname for a cmdlet.

powershell
Get-Alias dir
output
CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           dir -> Get-ChildItem
AliasCmdlet
dir, ls, gciGet-ChildItem
cd, slSet-Location
pwd, glGet-Location
cat, type, gcGet-Content
copy, cpCopy-Item
move, mvMove-Item
del, rmRemove-Item
cls, clearClear-Host
echoWrite-Output
?, whereWhere-Object
%, foreachForEach-Object
Watch outOn Linux and macOS, ls, cat, cp, mv, rm and clear are not aliases; they run the normal Linux tools. Use full cmdlet names in scripts so they work everywhere.

Cmdlet vs function vs program

  • Cmdlet: compiled into PowerShell (C#/.NET), e.g. Get-Process.
  • Function: written in PowerShell itself, e.g. help.
  • Application: an outside program (.exe), e.g. ping.
powershell
Get-Command Get-Process, help, ping
output · sample, yours will differ
CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Cmdlet          Get-Process                                        7.0.0.0    Microsoft.PowerShell.Management
Function        help
Application     PING.EXE                                           10.0.2261… C:\Windows\system32\PING.EXE

Try it

  1. Find all cmdlets with the verb Import.
  2. Which cmdlet does the alias gc run?
  3. Show the first 3 lines of datasets/app.log using a named parameter.
  4. List everything in datasets, including subfolders, using a switch.
Answers
powershell
Get-Command -Verb Import
Get-Alias gc                                   # gc -> Get-Content
Get-Content -Path datasets/app.log -TotalCount 3
Get-ChildItem datasets -Recurse

Remember

  • Cmdlets are Verb-Noun, noun singular.
  • Parameters: named (-Path x), positional (x), switch (-Recurse).
  • Get-Command finds commands; Get-Alias explains nicknames.
  • Use full names in scripts, aliases only when typing.
VivaWhat is a cmdlet? A cmdlet is a lightweight, built-in .NET command in PowerShell named as Verb-Noun, such as Get-Service. It returns objects, and its behaviour is changed with parameters.
