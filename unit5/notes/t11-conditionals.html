if, else & switch

Conditionals let a script make decisions: run this code only when something is true.

Topic 11~20 min
Before this:08 Variables09 User input10 Operators
Key idea

PowerShell checks conditions top to bottom and runs the block of the first one that is $true. Use if for a few checks, switch for one value with many cases.

if

The condition goes in ( ). The code to run goes in { }.

powershell
$marks = 72
if ($marks -ge 40) { "Pass" }
output
Pass
Watch outCompare with -gt, -eq, not > or =. if ($marks > 40) writes a file named 40, and if ($marks = 40) assigns 40.

if / else and elseif

else runs when the condition is false.

powershell
$marks = 35
if ($marks -ge 40) { "Pass" } else { "Fail" }
output
Fail

Add elseif for more than two choices. Put the strictest check first.

  • Check 1
  • true? run it, stop
  • else check 2
  • …
  • nothing matched: else
powershell
$marks = 72
if ($marks -ge 90) {
    "Grade A"
}
elseif ($marks -ge 75) {
    "Grade B"
}
elseif ($marks -ge 40) {
    "Grade C"
}
else {
    "Fail"
}
output
Grade C

Nested and combined conditions

An if can sit inside another if.

powershell
$age = 20
$hasId = $true
if ($age -ge 18) {
    if ($hasId) { "Entry allowed" } else { "Show your ID" }
}
else {
    "Too young"
}
output
Entry allowed

Often -and / -or is shorter than nesting.

powershell
$maths = 92; $science = 85
if ($maths -ge 80 -and $science -ge 80) { "Merit in both" }
if ($maths -lt 40 -or $science -lt 40)  { "Needs support" } else { "No support needed" }
output
Merit in both
No support needed
OperatorTrue when
-andboth sides are true
-orat least one side is true
-not or !the condition is false, e.g. if (-not $hasId)

switch

switch compares one value against many cases. default runs when nothing matches. Matching ignores case.

powershell
$day = 'sat'
switch ($day) {
    'Sat'   { 'Weekend' }
    'Sun'   { 'Weekend' }
    default { 'Weekday' }
}
output
Weekend

-Wildcard and -Regex

powershell
$server = 'web02'
switch -Wildcard ($server) {
    'web*'  { 'Web server' }
    'db*'   { 'Database server' }
    default { 'Other' }
}

$line = '2026-11-16 08:42:57 ERROR Failed to send email'
switch -Regex ($line) {
    'ERROR' { 'Problem found' }
    'WARN'  { 'Check this' }
}
output
Web server
Problem found

Script-block conditions and break

A case can be a test in { }. $_ is the value being checked. Unlike if, every matching case runs.

powershell
$marks = 85
switch ($marks) {
    { $_ -ge 75 } { 'Distinction' }
    { $_ -ge 40 } { 'Pass' }
}
output
Distinction
Pass

Add break to stop after the first match.

powershell
switch ($marks) {
    { $_ -ge 75 } { 'Distinction'; break }
    { $_ -ge 40 } { 'Pass'; break }
    default       { 'Fail' }
}
output
Distinction

switch over an array

Give switch many values and it checks each one in turn.

powershell
switch -Wildcard (Get-Content datasets/servers.txt) {
    'web*'  { "$_ : web" }
    'db*'   { "$_ : database" }
    default { "$_ : other" }
}
output
web01 : web
web02 : web
db01 : database
mail01 : other
backup01 : other
NoteWith an array, break stops the whole switch. Use continue to skip to the next item.

Which to use

SituationUse
One yes/no checkif
Two outcomesif / else
Ranges (marks, sizes, ages)if / elseif / else
Several different variables in one testif with -and / -or
One value, many fixed options (menu choice, day)switch
Match patterns like web*switch -Wildcard or -Regex
Check every item of a listswitch over an array

Try it

  1. Set $temp = 31. Print Hot above 30, Warm from 20 to 30, else Cold.
  2. Set $choice = '2'. Use switch to print Start for 1, Stop for 2, Unknown otherwise.
  3. Using switch -Regex, print Has digits if $name = 'web01' contains a digit.
Answers
powershell
$temp = 31
if ($temp -gt 30) { 'Hot' } elseif ($temp -ge 20) { 'Warm' } else { 'Cold' }    # Hot

$choice = '2'
switch ($choice) { '1' { 'Start' } '2' { 'Stop' } default { 'Unknown' } }       # Stop

$name = 'web01'
switch -Regex ($name) { '\d' { 'Has digits' } }                                  # Has digits

Remember

  • if (condition) { code }, then optional elseif and else.
  • Use -eq, -gt, -le… never = or > in a condition.
  • switch runs every matching case; add break to stop at the first.
  • switch has default, -Wildcard, -Regex and works on arrays.
VivaHow is PowerShell's switch different from C's? It does not fall through, it can match wildcards, regex and script-block tests, it runs every matching case unless you use break, and it can loop over an array.
