Introduction to PowerShell

PowerShell is a command-line shell and a scripting language from Microsoft, used to control and automate computers.

Topic 01~15 min
Before this:F1 What is a shell?F2 Install & open
Key idea

PowerShell = shell (type commands) + language (write scripts), built on .NET. Its commands return objects, not plain text.

What it is

A shellGet-Date

Type a command, press Enter, see the result.

A scripting languagehello.ps1

Save commands in a file with variables, loops and functions.

Built on .NET[math]::Sqrt(16)

You can use .NET classes and methods directly.

Object-based(Get-Date).Year

Results are objects with properties, not just text.

A short history

VersionYearWhat changed

NoteWindows still ships 5.1 (powershell.exe). PowerShell 7 (pwsh.exe) installs next to it. Both can be used on the same PC.

What it is used for

System admin

Manage users, services, processes and settings.

Automation

Turn a boring manual job into a script you run any time.

Files & data

Read and write CSV, JSON, text and log files.

Remote work

Run commands on many servers at once.

Cloud

Manage Azure, AWS and Microsoft 365 with modules.

Reports

Collect information and save it as a file.

A first taste

Open PowerShell inside the unit5 folder and try these.

powershell
Get-Content datasets/servers.txt
output
web01
web02
db01
mail01
backup01

Each line is an object, so you can ask how many there are.

powershell
(Get-Content datasets/servers.txt).Count
output
5

A CSV becomes a table of objects. Pick the columns you want by name.

powershell
Import-Csv datasets/students.csv | Select-Object -First 3 Name, Maths
output
Name  Maths
----  -----
Aarav 92
Priya 67
Rohan 45

Try it

  1. Check your PowerShell version.
  2. Show today's date, then only the year.
  3. Count the lines in datasets/numbers.txt.
Answers
powershell
$PSVersionTable.PSVersion
Get-Date
(Get-Date).Year
(Get-Content datasets/numbers.txt).Count    # 8

Remember

  • PowerShell is a shell and a scripting language, built on .NET.
  • 5.1 = Windows PowerShell (Windows only). 7 = PowerShell (pwsh, cross-platform).
  • Commands return objects, so you use properties instead of cutting text.
