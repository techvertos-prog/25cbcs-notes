Script files

Turn loose commands into tidy, reusable scripts that take parameters, find their own files, and share code.

Topic 19~25 min
Before this:06 Writing scripts07 Comments15 Functions16 Scoping
Key idea

A script works like a function: param() at the top for input, output at the end. Use $PSScriptRoot so it finds its files from any folder.

Organise scripts in a folder

One job per script

Name it Verb-Noun, like a cmdlet.

Shared code in one place

A library file or a module.

No hard-coded paths

Build paths from $PSScriptRoot.

param() at the top of a script

param() must be the first code in the file (only comments and #Requires may come before it).

scripts/Get-StudentReport.ps1
#Requires -Version 7.0
param(
    [Parameter(Mandatory)]
    [string]$Class,

    [int]$PassMark = 40
)

$csv = "$PSScriptRoot/../datasets/students.csv"

Import-Csv $csv |
    Where-Object Class -eq $Class |
    ForEach-Object {
        $result = if ([int]$_.Maths -ge $PassMark) { 'Pass' } else { 'Fail' }
        "$($_.Name): $($_.Maths) $result"
    }

Run it with named arguments

powershell
./scripts/Get-StudentReport.ps1 -Class 10A
output
Aarav: 92 Pass
Priya: 67 Pass
Kabir: 33 Fail
powershell
./scripts/Get-StudentReport.ps1 -Class 10A -PassMark 70
output
Aarav: 92 Pass
Priya: 67 Fail
Kabir: 33 Fail

Leave out -Class and PowerShell asks for it, because it is Mandatory.

$PSScriptRoot: paths relative to the script

$PSScriptRoot is the folder the script file lives in. A plain relative path like datasets/students.csv is relative to where you are, which may be a different folder.

powershell
Set-Location ..                                   # move out of unit5
./unit5/scripts/Get-StudentReport.ps1 -Class 10B  # still finds the CSV
output
Rohan: 45 Pass
Sneha: 88 Pass
Ananya: 99 Pass
Path written asRelative to
datasets/students.csvyour current folder (changes)
"$PSScriptRoot/../datasets/students.csv"the script's own folder (fixed)
Note/ works as a path separator on Windows too. $PSScriptRoot is empty at the prompt; it only has a value inside a script.

Share code: dot-source a library

scripts/lib.ps1
function Get-Grade {
    param([int]$Marks)
    if ($Marks -ge 75) { 'A' } elseif ($Marks -ge 40) { 'B' } else { 'C' }
}

Dot-source it so its functions land in your scope (see 16 Scoping). Inside another script, write . "$PSScriptRoot/lib.ps1".

powershell
. ./scripts/lib.ps1
Get-Grade 82
Get-Grade 55
output
A
B

A module in brief

Save the same code as StudentTools.psm1. A module is loaded with Import-Module and can choose what to share.

scripts/StudentTools.psm1
function Get-Grade {
    param([int]$Marks)
    if ($Marks -ge 75) { 'A' } elseif ($Marks -ge 40) { 'B' } else { 'C' }
}
Export-ModuleMember -Function Get-Grade
powershell
Import-Module ./scripts/StudentTools.psm1
Get-Grade 30
Get-Command -Module StudentTools
output
C

A recommended script template

scripts/Verb-Noun.ps1
<#
.SYNOPSIS
    One line saying what the script does.
.EXAMPLE
    ./scripts/Verb-Noun.ps1 -Path datasets/students.csv
#>
#Requires -Version 7.0
param(
    [Parameter(Mandatory)]
    [string]$Path,
    [int]$Top = 5
)

$ErrorActionPreference = 'Stop'       # turn errors into catchable ones
. "$PSScriptRoot/lib.ps1"             # shared functions

try {
    $data = Import-Csv $Path
    # ... main work here ...
    $data | Select-Object -First $Top
}
catch {
    Write-Error "Failed: $($_.Exception.Message)"
    exit 1                            # non-zero = failure
}

  3. Dot-source lib.ps1 in the script and print each student's grade too.

Remember

  • param() comes first; run with -Name value.
  • [Parameter(Mandatory)] asks; defaults fill gaps.
  • $PSScriptRoot = the script's folder; use it for paths.
  • . ./lib.ps1 shares functions; Import-Module loads a .psm1.
  • #Requires checks version, modules or admin before running.
VivaWhy use $PSScriptRoot instead of a relative path? A relative path depends on the current folder of whoever runs the script. $PSScriptRoot is always the script's own folder, so the script finds its files wherever it is run from.
