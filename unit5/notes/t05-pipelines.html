Pipelines

The pipe | hands the output of one command to the next one, so small commands can work together.

Topic 05~20 min
Before this:F5 Objects03 Cmdlets04 Help
Key idea

PowerShell pipes objects, not plain text. The next command can read their properties directly, so you never have to cut columns out of text.

How a pipeline flows

  • Get data
  • Filter rows
  • Sort
  • Pick columns
  • Show or save
powershell
Get-Process | Where-Object CPU -gt 10 | Sort-Object CPU -Descending | Select-Object -First 3 Name, CPU
output · sample, yours will differ
Name        CPU
----        ---
pwsh      58.21
Code      41.07
explorer  12.90

The five pipeline cmdlets

Where-Object| Where-Object Qty -eq 0

Keep only matching rows.

Sort-Object| Sort-Object Price -Descending

Put rows in order.

Select-Object| Select-Object Name, Qty

Pick columns, or the first N rows.

Measure-Object| Measure-Object Qty -Sum

Count, sum, average, min, max.

ForEach-Object| ForEach-Object { $_.Name }

Run code once for each row.

$_ (also written $PSItem) means "the current object in the pipe".

Build one step at a time

We use datasets/inventory.csv. Import-Csv turns each line into an object with the properties Item, Category, Qty and Price.

1. Get the data

powershell
Import-Csv datasets/inventory.csv
output
Item      Category    Qty Price
----      --------    --- -----
Keyboard  Accessories 25  750
Mouse     Accessories 40  400
Monitor   Display     8   9500
Laptop    Computers   5   58000
USB Cable Accessories 0   150
Webcam    Accessories 12  2200
Printer   Peripherals 3   12500
Router    Network     0   3200

2. Filter: only out-of-stock items

powershell
Import-Csv datasets/inventory.csv | Where-Object { $_.Qty -eq 0 }
output
Item      Category    Qty Price
----      --------    --- -----
USB Cable Accessories 0   150
Router    Network     0   3200

3. Sort and pick columns

powershell
Import-Csv datasets/inventory.csv |
    Sort-Object { [int]$_.Price } -Descending |
    Select-Object -First 3 Item, Price
output
Item    Price
----    -----
Laptop  58000
Printer 12500
Monitor 9500
TipCSV values are text. [int]$_.Price turns them into numbers so 9500 sorts below 12500. A line that ends with | continues on the next line.

4. Measure

powershell
Import-Csv datasets/inventory.csv | Measure-Object -Property Qty -Sum -Average
output
Count             : 8
Average           : 11.625
Sum               : 93
Maximum           :
Minimum           :
StandardDeviation :
Property          : Qty

5. Save the result

powershell
Import-Csv datasets/inventory.csv |
    Where-Object { $_.Qty -eq 0 } |
    Export-Csv reorder.csv -NoTypeInformation

Get-Content reorder.csv
output
"Item","Category","Qty","Price"
"USB Cable","Accessories","0","150"
"Router","Network","0","3200"

Where the output can go

End the pipe withResult
Format-TableColumns on screen
Format-ListOne property per line
Out-File report.txtText file
Export-Csv data.csv -NoTypeInformationCSV file
ConvertTo-JsonJSON text
Out-GridViewClickable table window (Windows only)
Watch outPut Format-* last. After it, you have display formatting, not data, so Export-Csv or Sort-Object will give strange results.

Try it

  1. Show only items in the Accessories category.
  2. Show the 2 cheapest items.
  3. Count how many items have fewer than 10 in stock.
Answers
powershell
Import-Csv datasets/inventory.csv | Where-Object Category -eq 'Accessories'
Import-Csv datasets/inventory.csv | Sort-Object { [int]$_.Price } | Select-Object -First 2
(Import-Csv datasets/inventory.csv | Where-Object { [int]$_.Qty -lt 10 }).Count    # 5

Remember

  • | passes objects to the next command.
  • $_ is the current object.
  • Filter early with Where-Object, format last with Format-*.
VivaHow is the PowerShell pipeline different from the Bash pipeline? Bash passes text, so you cut out columns with tools like awk. PowerShell passes objects, so you use property names such as $_.Qty.
