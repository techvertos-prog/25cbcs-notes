Writing Scripts

A script is a text file of PowerShell commands, saved with the .ps1 extension, that you can run again and again.

Topic 06~20 min
Before this:F4 Files & folders02 Console & ISE05 Pipelines
Key idea

Anything you can type at the prompt, you can put in a .ps1 file. Run it with ./name.ps1.

  • Create .ps1
  • Write commands
  • Save
  • Run ./file.ps1

Create a script

WayCommand
VS Code (best)code hello.ps1
Notepad (Windows)notepad hello.ps1
From PowerShellNew-Item hello.ps1, then edit it
One line, no editorSet-Content hello.ps1 'Write-Output "Hello!"'

Put this in hello.ps1 and save it in the unit5 folder:

hello.ps1
Write-Output "Hello from my first script!"
Get-Date -Format "dddd"

Run it, and why ./ is needed

powershell
./hello.ps1
output · sample, the day will differ
Hello from my first script!
Tuesday

Without ./, PowerShell refuses:

powershell
hello.ps1
output · Windows
hello.ps1: The term 'hello.ps1' is not recognized as a name of a cmdlet, function, script file, or executable program.
Check the spelling of the name, or if a path was included, verify that the path is correct and try again.

Suggestion [3,General]: The command "hello.ps1" was not found, but does exist in the current location. PowerShell does not load commands from the current location by default. If you trust this command, instead type: ".\hello.ps1". See "get-help about_Command_Precedence" for more details.
Why?Safety. PowerShell never runs files from the current folder just by name, so a planted file called dir.ps1 can't trick you. ./ (or .\ on Windows) means "this folder, I'm sure".

Other ways: full path C:\scripts\hello.ps1, or from CMD: pwsh -File hello.ps1.

Execution policy (Windows only)

Windows uses an execution policy to decide whether scripts may run. It is a safety belt, not a security wall.

powershell
Get-ExecutionPolicy
output · sample, yours will differ
Restricted

If it is Restricted, running a script gives:

output · sample
File C:\Users\aarav\unit5\hello.ps1 cannot be loaded because running scripts is disabled on this system. For more information, see about_Execution_Policies at https:/go.microsoft.com/fwlink/?LinkID=135170.

Fix it for your user only (no admin needed):

powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
PolicyLocal scriptsDownloaded scripts
RestrictedBlockedBlocked
AllSignedOnly if signedOnly if signed
RemoteSignedRunOnly if signed
UnrestrictedRunRun, with a warning
BypassRunRun, no warning
Watch outOn Windows 10/11 the default is Restricted, and on Windows Server it is RemoteSigned. Always check with Get-ExecutionPolicy. On Linux and macOS the policy is always Unrestricted and cannot be changed.

Write-Output vs Write-Host

Write-OutputWrite-Host
Goes toThe pipeline (real output)The screen only
Can be piped / saved?YesNo
Colours?NoYes, -ForegroundColor
Use forResultsMessages to the user
powershell
(Write-Output "Hi" | Measure-Object).Count
(Write-Host "Hi" | Measure-Object).Count
output
1
Hi
0

The second line printed Hi on screen, but nothing went down the pipe, so the count is 0.

TipA plain string on its own line is output too: "Hello" works the same as Write-Output "Hello".

A first complete script

class-report.ps1
# class-report.ps1 : a tiny report from students.csv
$students = Import-Csv datasets/students.csv
Write-Host "=== Class Report ===" -ForegroundColor Cyan

Write-Output "Students in file: $($students.Count)"

$top = $students | Sort-Object { [int]$_.Maths } -Descending | Select-Object -First 1
Write-Output "Top in Maths: $($top.Name) ($($top.Maths))"

$fail = $students | Where-Object { [int]$_.Maths -lt 40 }
Write-Output "Below 40 in Maths: $($fail.Name)"
powershell
./class-report.ps1
output
=== Class Report ===
Students in file: 8
Top in Maths: Ananya (99)
Below 40 in Maths: Kabir

Try it

  1. Check your execution policy. If it is Restricted, change it for your user.
  2. Write servers.ps1 that prints "Servers:" in yellow, then the contents of datasets/servers.txt.
  3. Run it, then run ./servers.ps1 | Measure-Object. Why is the count 5, not 6?
Answers
servers.ps1
Write-Host "Servers:" -ForegroundColor Yellow
Get-Content datasets/servers.txt

The heading uses Write-Host, so it goes to the screen, not the pipeline. Only the 5 server names are counted.

Remember

  • Scripts are .ps1 text files; run them with ./name.ps1.
  • ./ is required because PowerShell won't run files from the current folder by name.
  • Set-ExecutionPolicy RemoteSigned -Scope CurrentUser allows your own scripts on Windows.
  • Write-Output for results, Write-Host for on-screen messages.
VivaWhat is an execution policy? A Windows safety setting that controls whether PowerShell scripts can run. Common values are Restricted, AllSigned, RemoteSigned, Unrestricted and Bypass. RemoteSigned runs local scripts but requires downloaded scripts to be signed.
