Comments

Comments are notes for humans. PowerShell skips them when it runs the script.

Topic 07~15 min
Before this:04 Help06 Writing scripts
Key idea

# comments one line. <# … #> comments a block. A block with keywords like .SYNOPSIS becomes real help for your script.

Single-line# note

Everything after # is ignored.

Inline$x = 5 # note

Code first, note at the end.

Block<# ... #>

Many lines at once.

Comment-based help.SYNOPSIS

Read by Get-Help.

Single-line and inline comments

powershell
# Read the server list
$servers = Get-Content datasets/servers.txt

$servers.Count    # how many servers
# Write-Output "this line is switched off"
output
5
Tip"Commenting out" a line with # is a quick way to switch it off while testing. In VS Code, Ctrl+/ toggles it.
Watch out# inside quotes is just text: "Room #5" prints Room #5.

Block comments

powershell
<#
  Author : Priya
  Date   : 2026-11-17
  Purpose: Count servers in the list
#>
(Get-Content datasets/servers.txt).Count
output
5

Comment-based help

Put a block comment with special keywords at the top of the script. Get-Help then treats it like any cmdlet's help.

KeywordWrite here
.SYNOPSISOne-line summary
.DESCRIPTIONLonger explanation
.PARAMETER NameWhat one parameter means
.EXAMPLEA sample command (can repeat)
.NOTESAuthor, date, version
top-students.ps1
<#
.SYNOPSIS
    Shows the top students in one subject.
.DESCRIPTION
    Reads datasets/students.csv and lists the best students
    for the subject you choose.
.PARAMETER Subject
    Maths, Science or English.
.PARAMETER Top
    How many students to show. Default is 3.
.EXAMPLE
    ./top-students.ps1 -Subject Science -Top 2
#>
param(
    [string]$Subject = 'Maths',
    [int]$Top = 3
)

Import-Csv datasets/students.csv |
    Sort-Object { [int]$_.$Subject } -Descending |
    Select-Object -First $Top Name, $Subject

Run it

powershell
./top-students.ps1 -Subject Science -Top 2
output
Name   Science
----   -------
Ananya 94
Sneha  91

powershell
Get-Help ./top-students.ps1

Watch outKeywords must start with a dot and be spelled exactly. One wrong keyword (say .SYNOPSYS) and Get-Help ignores the whole block.

Good comments

DoDon't
Say why: # CSV values are text, so cast to [int]Repeat the code: # set x to 5
Add comment-based help to every scriptLeave old, wrong comments behind
Keep comments short and currentWrite a paragraph for every line
Use <# #> for headersComment out code and forget it forever

Try it

  1. Add a block comment with your name and today's date to hello.ps1.
  2. Comment out one line and run the script again.
  3. Add .SYNOPSIS and .EXAMPLE help, then run Get-Help ./hello.ps1 -Examples.
Answers
hello.ps1
<#
.SYNOPSIS
    Says hello and shows the day.
.EXAMPLE
    ./hello.ps1
.NOTES
    Author: (your name), 2026-11-17
#>
Write-Output "Hello from my first script!"

Remember

  • # = one line; <# #> = a block.
  • Comment-based help (.SYNOPSIS, .DESCRIPTION, .EXAMPLE) goes at the top of the script.
  • Get-Help ./script.ps1 reads that help.
  • Good comments explain why, not what.
VivaWhat is comment-based help? A block comment (<# #>) at the start of a script or function that uses keywords such as .SYNOPSIS, .DESCRIPTION, .PARAMETER and .EXAMPLE. Get-Help reads it and shows it like the help for a built-in cmdlet.
