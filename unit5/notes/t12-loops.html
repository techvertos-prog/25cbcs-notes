Loops

A loop runs the same block of code again and again: once per item, or until a condition changes.

Topic 12~25 min
Before this:05 Pipelines10 Operators11 if, else & switch
Key idea

Have a list? Use foreach. Need to count? Use for. Waiting for something to change? Use while or do.

Runs at least once.

for: counting

  • Start: $i = 1
  • Test: $i -le 5?
  • Run the block
  • Step: $i++
  • back to Test
powershell
for ($i = 1; $i -le 5; $i++) {
    "Count $i"
}
output
Count 1
Count 2
Count 3
Count 4
Count 5

A multiplication table:

powershell
$n = 7
for ($i = 1; $i -le 5; $i++) {
    "$n x $i = $($n * $i)"

foreach and ForEach-Object

The foreach statement walks through a list. $s holds the current item.

powershell
$servers = Get-Content datasets/servers.txt
foreach ($s in $servers) {
    "Checking $s"
}
output
Checking web01
Checking web02
Checking db01
Checking mail01
Checking backup01

Add numbers from a file:

powershell
$total = 0
foreach ($line in Get-Content datasets/numbers.txt) {
    $total += [int]$line
}
"Total: $total"
output
Total: 155

ForEach-Object does the same job inside a pipeline. The current item is $_.

powershell
Import-Csv datasets/students.csv | ForEach-Object { "$($_.Name) scored $($_.Maths)" }

Vikram scored 58
Ananya scored 99

while, do-while, do-until

powershell
$count = 3
while ($count -gt 0) {
    "Launch in $count"
    $count--
}
"Go!"
output
Launch in 3
Launch in 2
Launch in 1
Go!

A do loop checks after the block, so it always runs at least once, even when the test is false from the start.

powershell
$n = 10
do { "n is $n"; $n++ } while ($n -lt 5)

$n = 1
do { "n is $n"; $n++ } until ($n -gt 3)
output
n is 10
n is 1
n is 2
n is 3

Tipdo … until fits "ask until the answer is valid", e.g. do { $a = Read-Host 'y/n' } until ($a -in 'y','n').

break, continue and ranges

continue skips to the next pass. break leaves the loop.

powershell
foreach ($n in 1..10) {
    if ($n % 2 -eq 0) { continue }   # skip even numbers
    if ($n -gt 7)     { break }      # stop after 7
    $n
}
output
1
3
5
7

a..b makes a range of numbers. It can count down too.

powershell
1..5 -join ' '
5..1 -join ' '
'a'..'e' -join ' '
output
1 2 3 4 5
5 4 3 2 1
a b c d e
5.1 noteLetter ranges like 'a'..'e' work only in PowerShell 7. Number ranges work everywhere.
Watch outInside ForEach-Object, break and continue do not act on the pipeline; they can stop your whole script. Use return to skip one item there.

Try it

  1. Print the 9 times table from 9 x 1 to 9 x 10 with for.
  2. Print only students with Maths below 50 using foreach and if.
  3. Count down from 5 to 1 with while.
Answers
powershell
for ($i = 1; $i -le 10; $i++) { "9 x $i = $(9 * $i)" }

foreach ($s in Import-Csv datasets/students.csv) {
    if ([int]$s.Maths -lt 50) { $s.Name }      # Rohan, Kabir
}

$n = 5
while ($n -ge 1) { $n; $n-- }

Remember

  • for counts, foreach walks a list, ForEach-Object works in a pipe.
  • while checks first; do checks last and runs at least once.
  • do-while repeats while true; do-until repeats until true.
  • continue skips one pass; break leaves the loop.
VivaWhat is the difference between do-while and do-until? Both run the block once before checking. do-while repeats while the condition is true; do-until repeats while it is false and stops once it becomes true.
