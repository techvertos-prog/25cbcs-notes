Working with Help

PowerShell explains itself: Get-Help, Get-Command and Get-Member answer almost every "how do I…?" question.

Topic 04~20 min
Before this:F5 Objects03 Cmdlets
Key idea

Three discovery commands: Get-Command finds a command, Get-Help explains how to use it, Get-Member shows what its output objects contain.

  • Get-Command
  • Get-Help
  • Run it
  • Get-Member

Step 1: download the help files

PowerShell ships with only short help. Download the full text once.

powershell
Update-Help -UICulture en-US -ErrorAction SilentlyContinue
Watch outIn Windows PowerShell 5.1, run this as Administrator. In PowerShell 7 it saves help for your user only, so no admin is needed. A few modules may fail to update; that is normal.

Get-Help and its switches

CommandShows
Get-Help Get-ContentShort summary and syntax
Get-Help Get-Content -ExamplesOnly the examples (start here!)
Get-Help Get-Content -DetailedSummary, parameters, examples
Get-Help Get-Content -FullEverything, including input/output types
Get-Help Get-Content -Parameter TotalCountOne parameter only
Get-Help Get-Content -OnlineOpens the web page in your browser
powershell
Get-Help Get-Content -Parameter TotalCount
output · sample, wording may differ
-TotalCount <System.Int64>
    Specifies the number of lines from the beginning of a file or other item. The default is -1 (all lines).

    Required?                    false
    Position?                    named
    Default value                -1
    Accept pipeline input?       True (ByPropertyName)
    Accept wildcard characters?  false

Reading a syntax block

syntax · trimmed
Get-Content [-Path] <string[]> [-TotalCount <long>] [-Tail <int>] [-Raw] [<CommonParameters>]
PieceMeaning
[-TotalCount <long>]Whole thing in [ ] = optional parameter.
[-Path] <string[]>Only the name is in [ ] = value is required, but you can skip typing -Path (positional).
<long>, <int>< > = the type of value to give (a number here).
<string[]>[] after a type = you may give several values, separated by commas.
[-Raw]No value type = a switch.
[<CommonParameters>]Shared parameters like -Verbose and -ErrorAction.

So this is valid: Get-Content datasets/numbers.txt -Tail 2

output
33
8

about_ topics

Concepts (not commands) are explained in about_ pages.

powershell
Get-Help about_*              # list them all
Get-Help about_Operators      # read one
Get-Help about_If
TipWildcards work: Get-Help *csv* lists every command and topic about CSV.

Get-Member: what is inside an object?

Pipe any output into Get-Member (alias gm) to see its properties (data) and methods (actions).

powershell
Import-Csv datasets/students.csv | Get-Member -MemberType NoteProperty
output
   TypeName: System.Management.Automation.PSCustomObject

Name    MemberType   Definition
----    ----------   ----------
Class   NoteProperty string Class=10A
English NoteProperty string English=78
Maths   NoteProperty string Maths=92
Name    NoteProperty string Name=Aarav
Science NoteProperty string Science=85
powershell
"hello" | Get-Member -Name Length, ToUpper
output
   TypeName: System.String

Name    MemberType Definition
----    ---------- ----------
ToUpper Method     string ToUpper(), string ToUpper(cultureinfo culture)
Length  Property   int Length {get;}
powershell
"hello".Length       # property: no brackets
"hello".ToUpper()    # method: needs ()
output
5
HELLO

Try it

  1. Show only the examples for Sort-Object.
  2. In the syntax of Get-ChildItem, is -Recurse a switch?
  3. Read the help topic about comparison operators.
  4. What properties does a Get-Date object have?
Answers
powershell
Get-Help Sort-Object -Examples
Get-Help Get-ChildItem          # [-Recurse] has no <type>, so yes, a switch
Get-Help about_Comparison_Operators
Get-Date | Get-Member -MemberType Property

Remember

  • Run Update-Help once (as admin on 5.1).
  • -Examples is the fastest way to learn a cmdlet.
  • In syntax: [ ] = optional, < > = value type, no type = switch.
  • Get-Member lists properties and methods of objects.
VivaName the three discovery cmdlets. Get-Command finds commands, Get-Help shows how to use them (with -Examples, -Detailed, -Full, -Online), and Get-Member shows the properties and methods of the objects a command returns.
