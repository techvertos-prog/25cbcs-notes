First commands & navigation

Find out where you are, move between folders, list what is inside, and use the keyboard shortcuts that save time.

Fundamentals F3~20 min
Before this:F1 What is a shell?F2 Install & open
Key idea

Three commands do most of the moving around: where am I (Get-Location), go there (Set-Location), what is here (Get-ChildItem).

The big three

CmdletShort aliasesDoes
Get-Locationpwd, glShows the current folder.
Set-Locationcd, sl, chdirMoves to another folder.
Get-ChildItemls, dir, gciLists files and folders.
Watch outOn Linux and macOS, ls runs the system's own ls, not Get-ChildItem. Use dir or gci there to get PowerShell objects.

Where am I?

powershell
Get-Location
output · sample, yours will differ
Path
----
C:\Users\aarav\unit5

What is here?

powershell
Get-ChildItem -Name
output · sample, yours will differ
assets
basics
datasets
labs
notes
reference
index.html

-Name shows names only. Without it you also get Mode, LastWriteTime and Length (size).

Go somewhere

powershell
Set-Location datasets
Get-ChildItem -Name
output
app.log
config.json
inventory.csv
numbers.txt
servers.txt
students.csv

Set-Location prints nothing. Your prompt changes to show the new folder.

Paths: absolute and relative

AbsoluteC:\Users\aarav\unit5

Full address from the drive or /. Works from anywhere.

Relativedatasets\students.csv

Starts from where you are now.

SymbolMeansExample
.This folderGet-ChildItem .
..One folder up (the parent)cd ..
..\..Two folders upcd ..\..
~Your home foldercd ~
\ or /Separator between folder namescd datasets/
powershell
cd ..        # back up to unit5
cd ~         # jump to home
cd -         # go back to the previous folder (PowerShell 6.2+)
TipBoth \ and / work on Windows. Use / if you want the same command to work on Linux and macOS too.

Keys that save time

KeyDoes
TabCompletes a command, parameter or path. Press again for the next match.
Shift+TabGoes back to the previous match.
Ctrl+SpaceShows all matches as a menu.
↑ / ↓Scrolls through commands you typed before.
Ctrl+CStops the command that is running now.
EscClears the line you are typing.

Try Tab: type Get-Chi and press Tab. It becomes Get-ChildItem. Type cd da and press Tab. It becomes cd .\datasets\ (./datasets/ on Linux and macOS).

Stop a long command

powershell
Start-Sleep -Seconds 100    # waits 100 seconds; press Ctrl+C to stop early

History and clearing the screen

powershell
Get-History
output · sample, yours will differ
  Id     Duration CommandLine
  --     -------- -----------
   1        0.015 Get-Location
   2        0.021 Get-ChildItem -Name
   3        0.002 Set-Location datasets
Get-Historyh, history

Lists this session's commands.

Invoke-History 2r 2

Runs command number 2 again.

Clear-Hostcls, clear

Wipes the screen. History is kept.

Try it

  1. From the unit5 folder, go into datasets and list the files.
  2. Go back up one level without typing the folder name.
  3. List the notes folder without moving into it.
  4. Show your history, then clear the screen.

Remember

  • pwd where, cd go, ls/dir list: all are aliases of PowerShell cmdlets.
  • . here, .. up, ~ home.
  • Tab completes, ↑ repeats, Ctrl+C stops.
VivaWhat is the difference between an absolute and a relative path? An absolute path gives the full location from the drive or root, such as C:\Users\aarav\unit5. A relative path starts from the current folder, such as datasets\students.csv or ..\notes.
