Install & open PowerShell

Get PowerShell 7 on your computer, open it, and check which version you are running.

Fundamentals F2~15 min
Before this:F1 What is a shell?
Key idea

There are two PowerShells. Windows PowerShell 5.1 is built into Windows. PowerShell 7 (pwsh) is the new one for every OS. Use 7.

The two PowerShells

Windows PowerShell 5.1PowerShell 7
Program namepowershell.exepwsh (pwsh.exe on Windows)
Runs onWindows onlyWindows, Linux, macOS
Comes withWindows (already installed)You install it
Built on.NET Framework.NET (modern, cross-platform)
PSEditionDesktopCore
UpdatesBug fixes onlyNew features
Window colourBlue by defaultBlack by default
NoteBoth can be installed side by side. Installing 7 does not remove 5.1.

Install PowerShell 7

Windowswinget install --id Microsoft.PowerShell --source winget

Run in any terminal. Or get it from the Microsoft Store.

macOSbrew install --cask powershell

Needs Homebrew.

Ubuntu / Debiansudo apt-get install -y powershell

First add Microsoft's package repository (see the official install page).

Then close and reopen your terminal so it finds pwsh.

Open it

WayHow
Start menuPress Win, type pwsh or PowerShell 7, press Enter.
Win + X menuPress Win+X, pick Terminal (or Windows PowerShell on older Windows).
Windows TerminalOpen it, click the ⌄ arrow next to the tab, choose PowerShell.
From another shellType pwsh and press Enter. Type exit to leave.
Linux / macOSOpen Terminal, type pwsh.
TipIn Windows Terminal, go to Settings → Startup → Default profile and choose PowerShell so 7 opens every time.

Check your version

$PSVersionTable is a built-in variable that describes your PowerShell.

powershell
$PSVersionTable
output · sample, yours will differ

Watch outThe old PowerShell ISE editor only runs 5.1. For PowerShell 7, use VS Code with the PowerShell extension.

Try it

  1. Open PowerShell 7 and run $PSVersionTable.
  2. Print only the edition. Is it Core or Desktop?
  3. On Windows, open Windows PowerShell 5.1 too and compare the two outputs.
Answers
powershell
$PSVersionTable
$PSVersionTable.PSEdition    # Core in pwsh, Desktop in 5.1

Remember

  • 5.1 = powershell, Windows only, edition Desktop.
  • 7 = pwsh, every OS, edition Core.
  • $PSVersionTable tells you which one you are in.
VivaHow do you find the installed PowerShell version? Run $PSVersionTable and read PSVersion, or run $PSVersionTable.PSVersion. PSEdition says Core for PowerShell 7 and Desktop for Windows PowerShell 5.1.
