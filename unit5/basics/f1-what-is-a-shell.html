What is a shell?

A shell is a program where you type a command, press Enter, and the computer does it.

Fundamentals F1~10 minNo setup needed
Key idea

In a shell you type what you want instead of clicking. Typed commands can be saved and repeated, which is why admins love them.

Four words to know

ShellPowerShell, Bash, cmd

The program that reads your command and runs it.

TerminalWindows Terminal

The window that shows the shell. It only displays text.

PromptPS C:\Users\aarav>

The text that says "I am ready, type now".

CommandGet-Date

One instruction you type after the prompt.

  • You type
  • Press Enter
  • Shell runs it
  • Output appears
  • New prompt
powershell
Get-Date
output · sample, yours will differ
Tuesday, 17 November 2026 10:30:15

Reading the prompt

prompt
PS C:\Users\aarav> _
PartMeaning
PSYou are in PowerShell.
C:\Users\aaravThe folder you are in now (on Linux or macOS it looks like /home/aarav).
>End of the prompt. Type after it.
TipYou never type the prompt yourself. In these notes, code boxes show only what you type.

Why admins script

Fast

One line does what takes many clicks.

Repeatable

Same steps, same result, every time.

Scales

Works on 1 server or 500.

Recorded

The script is a written record of what was done.

Example: datasets/servers.txt lists five servers. One command reads them all.

powershell
Get-Content datasets/servers.txt
output
web01
web02
db01
mail01
backup01

Anatomy of a command line

powershell
Get-ChildItem -Path datasets -Filter *.csv -Name
PieceRoleMeaning
Get-ChildItemCommandWhat to do: list items in a folder.
-PathParameterAn option. It always starts with -.
datasetsValueThe setting for -Path: which folder.
-FilterParameterOnly keep matching names.
*.csvValueThe pattern: names ending in .csv.
-NameSwitchA parameter with no value. Being there turns it on: show names only.
output
inventory.csv
students.csv
NoteSpaces separate the pieces. PowerShell does not care about upper or lower case: get-childitem works too.

Try it

  1. Name the three parts of the prompt PS C:\Windows>.
  2. In Get-Content -Path datasets/numbers.txt, which piece is the command, the parameter and the value?
  3. Give one job that is easier in a GUI and one that is easier in a CLI.
Answers
  1. PS = PowerShell, C:\Windows = current folder, > = end of prompt.
  2. Command Get-Content, parameter -Path, value datasets/numbers.txt.
  3. GUI: editing a photo. CLI: renaming 200 files or checking 50 servers.

Remember

  • Shell = runs commands. Terminal = the window. Prompt = "type here".
  • A command line is: command, then -Parameter value pairs.
  • CLI work can be saved as a script and repeated.
VivaWhat is the difference between a shell and a terminal? The shell (such as PowerShell) understands and runs commands. The terminal (such as Windows Terminal) is only the window that shows the text going in and out.
