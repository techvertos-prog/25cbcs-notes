Files & folders

Create, read, write, copy, move, rename and delete files from the command line.

Fundamentals F4~20 min
Before this:F3 First commands & navigation
Key idea

Every file job has a cmdlet named Verb-Item or Verb-Content. Item = the file or folder itself. Content = the text inside it.

The whole set

CmdletAliasDoes
New-ItemniMake a file or folder
Get-Contentgc, cat, typeRead a file
Set-ContentWrite a file (replaces old text)
Add-ContentAdd text to the end
Copy-Itemcopy, cpCopy
Move-Itemmove, mvMove
Rename-ItemrenRename
Remove-Itemdel, rmDelete
Test-PathDoes it exist? True / False

On Linux and macOS, names like cat, cp, mv and rm run the system tools instead, so use the full cmdlet names.

Create a practice folder

Work inside playground so nothing important gets touched.

powershell
New-Item -ItemType Directory -Name playground
Set-Location playground
output · sample, yours will differ
    Directory: C:\Users\aarav\unit5

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          17-11-2026    10:30                playground

Make a file

powershell
New-Item -ItemType File -Name notes.txt
output · sample, yours will differ
    Directory: C:\Users\aarav\unit5\playground

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          17-11-2026    10:31              0 notes.txt

Length 0 means the file is empty. d in Mode means directory.

Write and read text

  • Set-Content: replace
  • Add-Content: append
  • Get-Content: read
powershell
Set-Content notes.txt "Hello PowerShell"
Add-Content notes.txt "Second line"
Get-Content notes.txt
output
Hello PowerShell
Second line
Watch outSet-Content wipes what was there. Use Add-Content to keep old lines.

Copy, move, rename

powershell
Copy-Item notes.txt backup.txt              # now two files
New-Item -ItemType Directory -Name old | Out-Null   # Out-Null hides the output
Move-Item backup.txt old                    # backup.txt goes into old
Rename-Item notes.txt diary.txt             # new name, same file
Get-ChildItem -Name
Get-ChildItem old -Name
output
old
diary.txt
backup.txt
Copy-ItemCopy-Item a b

a stays, b is a new copy.

Move-ItemMove-Item a folder

a leaves here and goes there.

Rename-ItemRename-Item a b

Same place, new name.

Check and delete safely

powershell
Test-Path diary.txt
Remove-Item diary.txt -WhatIf
output · sample path, yours will differ
True
What if: Performing the operation "Remove File" on target "C:\Users\aarav\unit5\playground\diary.txt".

-WhatIf only tells you what would happen. Nothing is deleted. Happy? Run it for real:

powershell
Remove-Item diary.txt
Test-Path diary.txt
output
False
Safety tipAdd -WhatIf to any Remove-Item, Move-Item or Copy-Item first. Deleted items do not go to the Recycle Bin.

Clean up

powershell
Set-Location ..
Remove-Item playground -Recurse

-Recurse deletes the folder and everything inside it. Without it, PowerShell asks you to confirm first.

Try it

  1. Make playground again and go into it.
  2. Create todo.txt holding Buy milk, then add Call Priya as a second line.
  3. Copy datasets/servers.txt into the playground.
  4. Rename it to hosts.txt, then show its contents.
  5. Check what deleting todo.txt would do, without deleting it.
Answers
powershell
New-Item -ItemType Directory -Name playground
cd playground
Set-Content todo.txt "Buy milk"
Add-Content todo.txt "Call Priya"
Copy-Item ../datasets/servers.txt .
Rename-Item servers.txt hosts.txt
Get-Content hosts.txt
Remove-Item todo.txt -WhatIf

Remember

  • -ItemType Directory for a folder, -ItemType File for a file.
  • Set-Content replaces, Add-Content appends, Get-Content reads.
  • Test-Path checks, -WhatIf previews, -Recurse includes everything inside.
VivaWhat does -WhatIf do? It shows what a command would change without changing anything. It is a safe way to test Remove-Item or Move-Item before running them for real.
