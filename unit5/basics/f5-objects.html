Objects in 5 minutes

Everything PowerShell gives you is an object: a thing with named facts (properties) and actions (methods).

Fundamentals F5~15 min
Before this:F3 First commandsF4 Files & folders
Key idea

An object is like a student ID card: it has labelled fields you can read. Use a dot to read one: $card.Name.

The student card

The card

One object.

Name, Class, Marks

Properties: facts you read.

Print, Renew

Methods: things the card can do.

Each row of datasets/students.csv becomes one such card:

powershell
$card = Import-Csv datasets/students.csv | Select-Object -First 1
$card
output
Name    : Aarav
Class   : 10A
Maths   : 92
Science : 85
English : 78

Read one property with a dot:

powershell
$card.Name
$card.Maths
output
Aarav
92

A date is an object

Wrap a command in ( ) to use its result as an object.

powershell
(Get-Date).Year
(Get-Date).DayOfWeek
(Get-Date).AddDays(7).ToShortDateString()
output · sample, yours will differ
2026
Tuesday
24-11-2026

Peek inside: Get-Member

Why this matters: pipelines

Because rows are objects, the next command can ask for a property by name. No cutting text by position.

  • Import-Csv: cards
  • Where-Object: Maths ≥ 90
  • Select-Object: Name, Maths
powershell
Import-Csv datasets/students.csv |
    Where-Object { [int]$_.Maths -ge 90 } |
    Select-Object Name, Maths
output
Name   Maths
----   -----
Aarav  92
Ananya 99

$_ is "the current card". Full story in 05 Pipelines.

Try it

  1. Print the length of your own name in quotes.
  2. Print "powershell" in capitals.
  3. Print today's month number using Get-Date.
  4. Load the first student into $card and print only the English mark.
Answers
powershell
"Aarav".Length                  # 5
"powershell".ToUpper()          # POWERSHELL
(Get-Date).Month
$card = Import-Csv datasets/students.csv | Select-Object -First 1
$card.English                   # 78

Remember

  • Object = a thing with properties (facts) and methods (actions).
  • Property: .Name. Method: .ToUpper() with brackets.
  • | Get-Member lists everything an object has.
VivaWhat is the difference between a property and a method? A property holds a value about the object, such as "hello".Length. A method is an action the object can perform, called with brackets, such as "hello".ToUpper().
