config.json

App settings in JSON: text, a number, true/false, a list and a nested object.

datasets/config.json
{
  "AppName": "StudentPortal",
  "Version": "2.1.0",
  "Port": 8080,
  "DebugMode": false,
  "Admins": ["aarav", "sneha"],
  "Database": {
    "Server": "db01",
    "Name": "portal"
  }
}
powershell · load it
$config = Get-Content datasets/config.json -Raw | ConvertFrom-Json

Then read values with a dot: $config.Port, $config.Database.Server. -Raw reads the file as one string.

Try it

  1. Count the lines in servers.txt.
  2. Show only the WARN lines of app.log.
  3. Print the AppName from config.json.
Answers
powershell
(Get-Content datasets/servers.txt).Count                          # 5
Get-Content datasets/app.log | Select-String 'WARN'
(Get-Content datasets/config.json -Raw | ConvertFrom-Json).AppName  # StudentPortal

Remember

  • CSV → Import-Csv gives objects with column names as properties.
  • Text → Get-Content gives one string per line.
  • JSON → Get-Content -Raw | ConvertFrom-Json gives one object.
VivaWhy do we write [int]$_.Qty after Import-Csv? CSV values are always read as text. [int] converts them to numbers so comparisons and sorting work numerically.
