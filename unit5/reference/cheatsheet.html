Getting started · 01–04

01 Introduction · 02 Console & ISE · 03 Cmdlets · 04 Help

SyntaxMeaning
PowerShellShell + scripting language from Microsoft, built on .NET, works with objects.
pwsh / powershellStart PowerShell 7 / Windows PowerShell 5.1.
$PSVersionTableShow version and edition (Core = 7, Desktop = 5.1).
Console vs ISEConsole: type one line at a time. ISE: editor + console for 5.1 only. For 7, use VS Code.

-Name valueNamed parameter.
-RecurseSwitch parameter: no value, on when present.
Get-Alias lsWhat does an alias point to?

Get-Help Get-Process -ExamplesHelp with examples (-Full, -Online also work).
Update-HelpDownload the latest help files (run as admin on 5.1).
... | Get-MemberList an object's type, properties and methods.

Pipelines · 05

05 Pipelines

SyntaxMeaning
A | BSend A's output objects into B.
$_ or $PSItemThe current object in the pipe.
Where-Object { $_.Qty -eq 0 }Keep matching objects.
Sort-Object Price -DescendingSort.
Select-Object -First 3 Name, QtyPick objects or properties.
Measure-Object Qty -Sum -AverageCount, sum, average, min, max.
ForEach-Object { $_.Name }Run code per object.
Format-Table / Format-ListDisplay only. Put it last.
Export-Csv f.csv -NoTypeInformationSave objects to CSV.
Out-File f.txtSave text output to a file.

Scripts, comments, script files · 06, 07, 19

06 Writing scripts · 07 Comments · 19 Script files

SyntaxMeaning
hello.ps1A script is a text file ending in .ps1.
.\hello.ps1Run a script in this folder (the .\ is required).
Get-ExecutionPolicyShow whether scripts may run.
Set-ExecutionPolicy RemoteSigned -Scope CurrentUserAllow your own scripts (Windows).
# textSingle-line comment.
<# ... #>Block (multi-line) comment.
.SYNOPSIS, .DESCRIPTION, .EXAMPLEComment-based help keywords inside <# #>; read with Get-Help.
param([string]$Name)Script parameters (first line of the script).
.\greet.ps1 -Name PriyaPass a value to a script parameter.
. .\tools.ps1Dot-source: load its functions and variables into your session.
$PSScriptRootFolder the running script lives in.
.psm1 / Import-ModuleModule file / load a module.

Variables & input · 08, 09

08 Variables · 09 User input

SyntaxMeaning
$name = "Priya"Create or change a variable.
[int]$age = 20Variable locked to a type.
$x.GetType().NameShow a value's type.
"Hi $name"Double quotes: variables are expanded.
'Hi $name'Single quotes: text stays exactly as typed.
"Total: $($a + $b)"Run an expression inside a string.
$true, $false, $nullBuilt-in values.
Get-Variable / Remove-Variable xList / delete variables.
$n = Read-Host "Enter name"Ask the user. Always returns text.
[int](Read-Host "Age")Convert the answer to a number.
Read-Host "PIN" -AsSecureStringHide what is typed.
Write-Host "Hi" -ForegroundColor GreenPrint coloured text to the screen.

Operators · 10

10 Operators

SyntaxMeaning
+ - * / %Add, subtract, multiply, divide, remainder.
= += -= *= /=, ++, --Assign / update / add or subtract 1.
-eq -neEqual / not equal.
-gt -ge -lt -leGreater, greater-or-equal, less, less-or-equal.
-like 'a*'Wildcard match (*, ?).
-match '^\d+$'Regular-expression match.
-contains / -inIs the value in the list?
-and -or -not !Logical operators.
-replace 'a','b', -split ',', -join ','Text operators.
-ceq, -clike, -cmatchCase-sensitive versions (normal ones ignore case).
-is [int]Type check.
Watch out> and < are not comparisons in PowerShell. > writes output to a file.

Decisions & loops · 11, 12

11 if, else & switch · 12 Loops

SyntaxMeaning
if (cond) { } elseif (cond) { } else { }Run the first block whose condition is true.
switch ($x) { 1 { 'one' } default { 'other' } }Pick by value.
switch ($m) { { $_ -ge 90 } { 'A'; break } }Condition cases; break stops at first match.
switch -Wildcard / -RegexMatch cases by pattern.
for ($i = 1; $i -le 5; $i++) { }Counting loop.
foreach ($s in $list) { }Once per item in a collection.
while (cond) { }Check first, then repeat.
do { } while (cond) / do { } until (cond)Run at least once.
1..5Range: 1, 2, 3, 4, 5.
break / continueLeave the loop / skip to the next turn.

Arrays & hashtables · 13, 14

13 Arrays · 14 Hashtables

SyntaxMeaning
$a = @(10, 20, 30) or 10, 20, 30Make an array.
@()Empty array.
$a[0], $a[-1], $a[0..1]First, last, a slice.
$a.CountNumber of items.
$a += 40Add an item (makes a new array).
$a -contains 20Is 20 in the array?
$h = @{ Name = 'Aarav'; Marks = 92 }Make a hashtable (key = value).
$h.Name or $h['Name']Read a value by key.
$h.City = 'Pune' / $h.Add('City','Pune')Add a key.
$h.Remove('City')Delete a key.
$h.Keys, $h.Values, $h.ContainsKey('Name')All keys, all values, key exists?
[ordered]@{ }Hashtable that keeps insertion order.
[pscustomobject]@{ }Turn a hashtable into an object.

Functions & scope · 15, 16

15 Functions · 16 Scoping

SyntaxMeaning
function Get-Square { param([int]$N) $N * $N }Define a function with a parameter.
Get-Square -N 4 or Get-Square 4Call it (no brackets, no commas).
param([int]$N = 1)Default value.
[Parameter(Mandatory)]Ask for the value if it is missing.
return $xLeave the function; any uncaught output is also returned.
Local scopeVariables made inside a function vanish when it ends.
$global:xVisible everywhere in the session.
$script:xShared across the whole script file.
$local:xCurrent scope only.
Child reads parentA function can read outer variables but changes stay local unless a scope prefix is used.

Errors & profiles · 17, 18

17 Basic error handling · 18 Profiles

SyntaxMeaning
try { } catch { } finally { }Try code, handle failure, always clean up.
$_ in catchThe error; $_.Exception.Message is its text.
-ErrorAction StopTurn a non-terminating error into one catch can see.
-ErrorAction SilentlyContinueHide the error and carry on.
$ErrorActionPreference = 'Stop'Default for every command.
$Error[0]Most recent error.
throw "message"Raise your own error.
$PROFILEPath of your profile script (runs at every start).
Test-Path $PROFILEDoes it exist yet?
New-Item $PROFILE -ForceCreate it (with its folders).
notepad $PROFILE / code $PROFILEEdit it.
. $PROFILEReload it without restarting.
NotePowerShell 7 and 5.1 use different profile files. Check $PROFILE in each.

Everyday commands · F3, F4

F3 First commands · F4 Files & folders

SyntaxMeaning
Get-Location (pwd)Where am I?
Set-Location .. (cd)Move (here .. = up one).
Get-ChildItem (ls, dir)List a folder.
New-Item -ItemType File|Directory -Name xCreate a file or folder.
Get-Content / Set-Content / Add-ContentRead / overwrite / append text.
Copy-Item, Move-Item, Rename-ItemCopy, move, rename.
Remove-Item x -WhatIfPreview a delete safely.
Test-Path xTrue if it exists.

Remember

  • Comparisons are words: -eq, -gt, -like, never == or >.
  • Double quotes expand $variables, single quotes do not.
  • Filter early, format last; use -ErrorAction Stop so try/catch works.
VivaName three things that make PowerShell different from cmd. It passes objects through the pipeline, its commands follow a consistent Verb-Noun pattern, and it is a full scripting language with variables, loops, functions and try/catch.
