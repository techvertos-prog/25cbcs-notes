Task 3

Read help and examples

Download the help files once (run as Administrator on Windows), then ask for help.

powershell · console
Update-Help -UICulture en-US -ErrorAction SilentlyContinue   # once, needs internet

Get-Help Get-Process                 # short summary
Get-Help Get-Process -Examples       # only the examples
Get-Help Get-Process -Parameter Name # one parameter
Get-Help about_Pipelines             # a concept page

Task 4

Inspect objects with Get-Member

Pipe any output to Get-Member to see its type, properties and methods.

powershell · console
"hello" | Get-Member -MemberType Property
"hello".Length
"hello".ToUpper()
output
   TypeName: System.String

Name   MemberType Definition
----   ---------- ----------
Length Property   int Length {get;}

5
HELLO

Now try it on a CSV file. Each row becomes an object with one property per column.

powershell · console
Import-Csv datasets/students.csv | Get-Member -MemberType NoteProperty
output
   TypeName: System.Management.Automation.PSCustomObject

Name    MemberType   Definition
----    ----------   ----------
Class   NoteProperty string Class=10A
English NoteProperty string English=78
Maths   NoteProperty string Maths=92
Name    NoteProperty string Name=Aarav
Science NoteProperty string Science=85

Every value is a string, so you convert it with [int] before doing maths.

Task 5

Use aliases

An alias is a short name for a cmdlet.

powershell · console
Get-Alias dir, gci, cd
Get-Alias -Definition Get-ChildItem
output · sample, yours will differ
CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           dir -> Get-ChildItem
Alias           gci -> Get-ChildItem
Alias           cd -> Set-Location
Alias           dir -> Get-ChildItem
Alias           gci -> Get-ChildItem
Alias           ls -> Get-ChildItem

ls is an alias only on Windows. On macOS and Linux, ls runs the system's own ls program.

TipAliases save typing at the prompt. In scripts, write the full cmdlet name so others can read it.

Challenge

  1. Find every command whose noun is Item.
  2. Show the examples for Sort-Object.
  3. List the properties of the objects that Get-Date returns.
  4. Make your own alias gh for Get-Help.
Answers
powershell
Get-Command -Noun Item
Get-Help Sort-Object -Examples
Get-Date | Get-Member -MemberType Property
Set-Alias gh Get-Help      # lasts until you close the console

Viva questions

What does $PSVersionTable show?

Details about the running PowerShell: version, edition (Core or Desktop), OS and more.

What is the difference between Get-Command and Get-Help?

Get-Command finds which commands exist. Get-Help explains how to use one of them.

Why is Get-Member useful?

PowerShell returns objects. Get-Member shows their type and the properties and methods you can use, such as .Length or .ToUpper().

Is an alias the same as a cmdlet?

No. It is only another name that points to a cmdlet. Get-Alias shows what it points to.
