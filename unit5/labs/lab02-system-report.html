Lab 2: System report with pipelines

Chain cmdlets with | to find heavy processes and big files, total a stock list, and save the result as CSV and HTML.

Tasks

Task 1

Top 5 processes by memory

powershell · console
Get-Process |
    Sort-Object WorkingSet -Descending |
    Select-Object -First 5 Name, Id,
        @{ Name = 'MemoryMB'; Expression = { [math]::Round($_.WorkingSet / 1MB, 1) } }
output · sample, yours will differ
Name        Id MemoryMB
----        -- --------
Code      9120    612.4
msedge    4408    388.9
pwsh      7764    142.7
explorer  3312    120.3
Teams     6096     98.5

WorkingSet is memory in bytes. The @{ Name = ...; Expression = ... } part is a calculated property: a new column you compute.

Task 3

Stock value from inventory.csv

Keep items that are in stock, add a Value column (Qty × Price), and sort by it.

powershell · console
$stock = Import-Csv datasets/inventory.csv |
    Where-Object { [int]$_.Qty -gt 0 } |
    Select-Object Item, Qty, Price,
        @{ Name = 'Value'; Expression = { [int]$_.Qty * [int]$_.Price } } |
    Sort-Object Value -Descending

$stock
output
Item     Qty Price  Value
----     --- -----  -----
Laptop   5   58000 290000
Monitor  8   9500   76000
Printer  3   12500  37500
Webcam   12  2200   26400
Keyboard 25  750    18750
Mouse    40  400    16000

Value is a real number, so it is right-aligned. Qty and Price are still text from the CSV, so they are left-aligned.

Task 5

Export to CSV and HTML

powershell · console
$stock | Export-Csv stock.csv -NoTypeInformation
Get-Content stock.csv -TotalCount 3
output
"Item","Qty","Price","Value"
"Laptop","5","58000","290000"
"Monitor","8","9500","76000"
powershell · console
$stock |
    ConvertTo-Html -Title 'Stock report' -PreContent '<h1>Stock report</h1>' |
    Out-File stock.html

Invoke-Item stock.html     # opens it in your browser (Windows)

There is no output on screen. ConvertTo-Html builds an HTML table and Out-File saves it. On macOS use open stock.html; on Linux use xdg-open stock.html.

Viva questions

What is a calculated property?

A hashtable @{ Name = ...; Expression = { ... } } given to Select-Object. It adds a new column whose value is computed for each object.

Why write [int]$_.Qty and not just $_.Qty?

CSV values are text. [int] turns them into numbers so comparison and multiplication work correctly.

What is the difference between Export-Csv and Out-File?

Export-Csv saves the object data as CSV. Out-File saves whatever text you send it, exactly as it would appear on screen.

Why should Format-Table not come before Export-Csv?

Format-Table turns objects into display instructions. After it, the real properties are gone, so the CSV would be useless.
