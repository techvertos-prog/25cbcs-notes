Task 1

Multiplication table with for

powershell · table.ps1
$n = 7
for ($i = 1; $i -le 10; $i++) {
    "{0} x {1,2} = {2,3}" -f $n, $i, ($n * $i)
}
output
7 x  1 =   7
7 x  2 =  14
7 x  3 =  21
7 x  4 =  28
7 x  5 =  35
7 x  6 =  42
7 x  7 =  49
7 x  8 =  56
7 x  9 =  63
7 x 10 =  70

The three parts are: start ($i = 1), keep going while ($i -le 10), and step ($i++).

Task 2

foreach over servers.txt

powershell · servers.ps1
$servers = Get-Content datasets/servers.txt
$num = 0
foreach ($s in $servers) {
    $num++
    if ($s -like 'web*') { $role = 'Web server' } else { $role = 'Other' }
    "{0}. {1,-9} {2}" -f $num, $s, $role
}
"Total servers: $($servers.Count)"
output
1. web01     Web server
2. web02     Web server
3. db01      Other
4. mail01    Other
5. backup01  Other
Total servers: 5

Get-Content returns an array with one item per line, so foreach visits each server name in turn.

Task 3

Countdown with while

powershell · countdown.ps1
$n = 5
while ($n -gt 0) {
    "T-minus $n"
    Start-Sleep -Seconds 1
    $n--
}
"Lift off!"
output
T-minus 5
T-minus 4
T-minus 3
T-minus 2
T-minus 1
Lift off!

If you forget $n--, the condition never becomes false and the loop runs forever. Press Ctrl+C to stop it.

Task 4

Guess the number with do-until

The secret is fixed at 42 so your output matches ours. Later, try Get-Random -Minimum 1 -Maximum 101.

powershell · guess.ps1
$secret = 42
$tries  = 0
do {
    [int]$guess = Read-Host "Guess (1-100)"
    $tries++
    if ($guess -lt $secret)     { "Too low" }
    elseif ($guess -gt $secret) { "Too high" }
} until ($guess -eq $secret)

"Correct! You took $tries tries."
output
Guess (1-100): 50
Too high
Guess (1-100): 30
Too low
Guess (1-100): 42
Correct! You took 3 tries.

The body runs first and the test comes after, so the user is always asked at least once.

Task 5

Count log levels with ForEach-Object

Each line of datasets/app.log has a level: INFO, WARN or ERROR.

powershell · loglevels.ps1
$info = 0; $warn = 0; $err = 0

Get-Content datasets/app.log | ForEach-Object {
    if ($_ -match ' INFO ')      { $info++ }
    elseif ($_ -match ' WARN ')  { $warn++ }
    elseif ($_ -match ' ERROR ') { $err++ }
}

"INFO : $info"
"WARN : $warn"
"ERROR: $err"
"Total: $($info + $warn + $err) lines"
output
INFO : 8
WARN : 3
ERROR: 3
Total: 14 lines

Inside ForEach-Object, $_ is the current line.

Challenge

  1. Print the 7 times table backwards, from 10 down to 1.
  2. Add up all numbers in datasets/numbers.txt with foreach. (Answer: 155.)
  3. Print only the ERROR lines of app.log, using continue to skip the rest.
  4. Get the same log counts in one line with Group-Object.

Viva questions

What is the difference between while and do-until?

while tests first, so it may run zero times. do-until runs the body first and stops when the test becomes true, so it runs at least once.

What is the difference between foreach and ForEach-Object?

foreach is a language keyword that loops over a list you already have. ForEach-Object is a cmdlet that handles items one by one as they come through a pipe.

What do break and continue do?

break leaves the loop completely. continue skips the rest of this pass and moves to the next item.
