Lab 9: Customise your profile

Your profile is a script that runs every time PowerShell starts. Add an alias, a greeting, a function and your own prompt to it.

Lab 9Beginner~30 min
Topics used:18 Profiles15 Functions03 Cmdlets

  • Find your profile path with $PROFILE.
  • Create the profile file safely.
  • Add an alias, a greeting, a function and a custom prompt.
  • Reload it, and start PowerShell without it.

Tasks

Task 1

Check $PROFILE

powershell · console
$PROFILE
Test-Path $PROFILE
output · sample, yours will differ
C:\Users\you\Documents\PowerShell\Microsoft.PowerShell_profile.ps1
False

False means the file does not exist yet. On macOS and Linux the path is ~/.config/powershell/Microsoft.PowerShell_profile.ps1.

PropertyRuns for
$PROFILE.CurrentUserCurrentHostYou, in this program (same as $PROFILE)
$PROFILE.CurrentUserAllHostsYou, in every PowerShell program (console, VS Code)
$PROFILE.AllUsersAllHostsEvery user (needs admin rights)
Task 2

Create the profile safely

Create it only if it is missing, so you never wipe an existing one.

powershell · console
if (-not (Test-Path $PROFILE)) {
    New-Item -ItemType File -Path $PROFILE -Force | Out-Null
    "Profile created"
} else {
    Copy-Item $PROFILE "$PROFILE.bak"
    "Profile exists, backup saved"
}
output
Profile created

-Force also creates any missing folders in the path. Now open it: notepad $PROFILE (Windows) or code $PROFILE (any OS).

Windows onlyThe profile is a script, so the execution policy must allow it. If you see "running scripts is disabled", run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned (see Lab 3).
Task 3

Add an alias, a greeting and a function

Type this into the profile file and save it.

powershell · Microsoft.PowerShell_profile.ps1
# ---- My PowerShell profile ----

# Alias: short name for a cmdlet
Set-Alias -Name ll -Value Get-ChildItem

# Function: today's date in a friendly format
function Show-Today {
    Get-Date -Format 'dddd, dd MMMM yyyy'
}

# Greeting shown at start-up
Write-Host "Welcome back, $([Environment]::UserName)!" -ForegroundColor Cyan
Write-Host "PowerShell $($PSVersionTable.PSVersion) is ready."

[Environment]::UserName gives your login name on Windows, macOS and Linux.

Task 4

Add a custom prompt

The prompt is just a function named prompt. Whatever it returns is shown before your cursor. Add this to the profile too.

powershell · Microsoft.PowerShell_profile.ps1 (add)
function prompt {
    $folder = Split-Path -Leaf (Get-Location)
    "[$(Get-Date -Format 'HH:mm')] $folder> "
}
output · sample, yours will differ
[10:42] unit5>

Split-Path -Leaf keeps only the last folder name, so the prompt stays short.

Task 5

Reload and test

Load the profile into the current session without restarting.

Now start a fresh PowerShell that skips the profile:

powershell · console
pwsh -NoProfile
ll
output
ll: The term 'll' is not recognized as a name of a cmdlet, function, script file, or executable program.
Check the spelling of the name, or if a path was included, verify that the path is correct and try again.

-NoProfile is handy when a broken profile stops PowerShell from starting cleanly. Type exit to go back.

Viva questions

What is a PowerShell profile?

A script that runs automatically every time PowerShell starts. You use it to load aliases, functions and settings.

Why are aliases made at the prompt lost when you close PowerShell?

They live only in that session. Putting them in the profile recreates them each time.

What does . $PROFILE do?

It dot-sources the profile, running it in the current session so the changes apply now.

How do you start PowerShell without the profile?

pwsh -NoProfile (or powershell -NoProfile for Windows PowerShell 5.1).
