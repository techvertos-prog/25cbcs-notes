Tasks

Type Tasks 1–4 straight into the console to try them. In Task 6 you save them in a file.

Task 1

Get-Square

powershell · console
function Get-Square {
    param([int]$Number)
    $Number * $Number
}

Get-Square 7
Get-Square -Number 12
output
49
144

Any value a function outputs is its return value. You do not need the word return.

Task 2

Get-Average with an array parameter

powershell · console
function Get-Average {
    param([int[]]$Numbers)
    $sum = 0
    foreach ($n in $Numbers) { $sum += $n }
    $sum / $Numbers.Count
}

Get-Average -Numbers 10, 20, 30, 45
Get-Average -Numbers (Get-Content datasets/numbers.txt)
output
26.25
19.375

[int[]] means "an array of whole numbers". The lines of numbers.txt are converted to numbers automatically.

Task 3

Test-Even returns True or False

powershell · console
function Test-Even {
    param([int]$Number)
    return ($Number % 2 -eq 0)
}

Test-Even 10
Test-Even 7
1..4 | ForEach-Object { "$_ is even: $(Test-Even $_)" }
output
True
False
1 is even: False
2 is even: True
3 is even: False
4 is even: True

By convention, a Test- function answers a yes/no question.

Task 4

Get-Grade with a default parameter

powershell · console
function Get-Grade {
    param(
        [Parameter(Mandatory)][int]$Marks,
        [int]$PassMark = 40          # used when you do not give one
    )
    if ($Marks -ge 90)        { 'A' }
    elseif ($Marks -ge 75)    { 'B' }
    elseif ($Marks -ge 60)    { 'C' }
    elseif ($Marks -ge $PassMark) { 'D' }
    else                      { 'F' }
}

Get-Grade 82
Get-Grade 45
Get-Grade 45 -PassMark 50
output
B
D
F

Mandatory makes PowerShell ask for -Marks if you leave it out. $PassMark is 40 unless you pass another value.

Task 5

Scope demo

powershell · console
$x = 10

function Test-Scope {
    $x = 99                 # a new local $x
    "Inside:  x = $x"
}
function Set-X {
    $script:x = 99          # change the outer $x
}

Test-Scope
"Outside: x = $x"
Set-X
"After Set-X: x = $x"
output
Inside:  x = 99
Outside: x = 10
After Set-X: x = 99

A function can read outer variables, but assigning creates a local copy. Use $script: (or $global:) to change the outer one.

Viva questions

Why use param() instead of $args?

param() gives each input a name, a type, a default and rules such as Mandatory. $args is just an unnamed list.

What is a default parameter value?

A value the parameter uses when the caller does not give one, such as [int]$PassMark = 40.

What is dot-sourcing?

Running a script with . ./file.ps1. Its functions and variables are loaded into the current scope instead of disappearing when it ends.

Name the main scopes.

Global (the console session), Script (one script file) and Local (the current function or block).
