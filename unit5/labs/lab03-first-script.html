Tasks

Task 1

Create hello.ps1

Open an editor from the unit5 folder: code hello.ps1 (VS Code) or notepad hello.ps1 (Windows). Type this and save.

powershell · hello.ps1
Write-Output "Hello, PowerShell!"
Write-Output "Today is $(Get-Date -Format 'dddd')."
powershell · run it
./hello.ps1
output · sample, yours will differ
Hello, PowerShell!
Today is Tuesday.

Always start with ./. PowerShell does not run scripts from the current folder by name alone.

Task 2

Set the execution policy (Windows)

If Windows says scripts are disabled, check and change the policy for your user only.

powershell · console
Get-ExecutionPolicy
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Get-ExecutionPolicy
output · sample, yours will differ
Restricted
RemoteSigned

RemoteSigned runs your own scripts but blocks unsigned ones downloaded from the internet. On macOS and Linux the policy is always Unrestricted, so skip this task.

Task 3

Variables and comments

powershell · info.ps1
# info.ps1: store values in variables
$name = "Aarav"     # text   (String)
$age  = 19          # whole number (Int32)
$cgpa = 8.7         # decimal (Double)

<#
  Double quotes expand variables.
  $( ) runs an expression inside a string.
#>
"Name: $name"
"Age next year: $($age + 1)"
'Single quotes do not expand: $name'
$cgpa.GetType().Name
output
Name: Aarav
Age next year: 20
Single quotes do not expand: $name
Double

# starts a one-line comment and <# ... #> wraps a block comment. PowerShell ignores both.

Task 4

Ask for a name and two numbers

powershell · calc.ps1
$name   = Read-Host "What is your name"
[int]$a = Read-Host "First number"
[int]$b = Read-Host "Second number"

Write-Host "Hi $name! You typed $a and $b."
output
What is your name: Priya
First number: 17
Second number: 5
Hi Priya! You typed 17 and 5.

Read-Host adds the : after the prompt and always returns text; [int] makes it a number.

Try without [int]Without [int], $a + $b joins the text: "17" + "5" gives 175, not 22.
Task 5

Calculator with formatted output

Add these lines to the end of calc.ps1.

powershell · calc.ps1 (continued)
"{0,-12}{1,8}"    -f 'Addition',    ($a + $b)
"{0,-12}{1,8}"    -f 'Subtraction', ($a - $b)
"{0,-12}{1,8}"    -f 'Multiply',    ($a * $b)
"{0,-12}{1,8:N2}" -f 'Division',    ($a / $b)
"{0,-12}{1,8}"    -f 'Remainder',   ($a % $b)
output
What is your name: Priya
First number: 17
Second number: 5
Hi Priya! You typed 17 and 5.
Addition          22
Subtraction       12
Multiply          85
Division        3.40
Remainder          2
Format itemMeaning
{0,-12}Value 0, left-aligned in 12 characters
{1,8}Value 1, right-aligned in 8 characters
{1,8:N2}Same, with 2 decimal places

Viva questions

Why do we type ./hello.ps1 and not just hello.ps1?

For safety, PowerShell does not run scripts from the current folder unless you give a path. ./ means "this folder".

What does the execution policy RemoteSigned allow?

Local scripts run freely. Scripts downloaded from the internet must be signed by a trusted publisher.

What is the difference between "$name" and '$name'?

Double quotes replace $name with its value. Single quotes print the text exactly as typed.

What does % do?

It gives the remainder of a division: 17 % 5 is 2.
