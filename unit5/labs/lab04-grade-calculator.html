Tasks

Task 1

Grade with if / elseif

powershell · grade.ps1
# grade.ps1: ask for marks and print a grade
[int]$marks = Read-Host "Enter marks (0-100)"

if ($marks -ge 90)     { $grade = 'A' }
elseif ($marks -ge 75) { $grade = 'B' }
elseif ($marks -ge 60) { $grade = 'C' }
elseif ($marks -ge 40) { $grade = 'D' }
else                   { $grade = 'F' }

Write-Host "Marks: $marks  Grade: $grade"
powershell · run it
./grade.ps1
output
Enter marks (0-100): 82
Marks: 82  Grade: B

The checks run top to bottom and stop at the first one that is true, so 82 fails -ge 90 and matches -ge 75.

Task 3

Same logic with switch

powershell · grade-switch.ps1
[int]$marks = Read-Host "Enter marks (0-100)"

$grade = switch ($marks) {
    { $_ -ge 90 } { 'A'; break }
    { $_ -ge 75 } { 'B'; break }
    { $_ -ge 60 } { 'C'; break }
    { $_ -ge 40 } { 'D'; break }
    default       { 'F' }
}
"Grade: $grade"
output
Enter marks (0-100): 95
Grade: A
Why break?Without break, switch keeps testing. 95 also matches -ge 75, -ge 60 and -ge 40, so you would get A B C D.
Task 4

Grade the whole class

Read datasets/students.csv and grade each student's Maths mark.

powershell · class-grades.ps1
foreach ($s in Import-Csv datasets/students.csv) {
    $m = [int]$s.Maths
    $grade = if ($m -ge 90) { 'A' } elseif ($m -ge 75) { 'B' } elseif ($m -ge 60) { 'C' } elseif ($m -ge 40) { 'D' } else { 'F' }
    "{0,-7} {1,3}  {2}" -f $s.Name, $m, $grade
}

Viva questions

What is the difference between if/elseif and switch?

if/elseif stops at the first true test. switch tests every case unless you use break. switch is cleaner when you compare one value against many cases.

Why do we write [int] before Read-Host?

Read-Host always returns text. [int] turns it into a number so -ge compares numbers, not text.

What does default do in a switch?

It runs when no other case matched, like else.
