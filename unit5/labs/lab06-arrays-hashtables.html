Task 1

An array of marks

powershell · marks.ps1
$marks = 78, 92, 65, 88, 71

"First: $($marks[0])  Last: $($marks[-1])  Count: $($marks.Count)"

$sum = 0
foreach ($m in $marks) { $sum += $m }
"Sum by loop: $sum"

$stats = $marks | Measure-Object -Sum -Average -Maximum -Minimum
"Sum: $($stats.Sum)  Average: $($stats.Average)  Max: $($stats.Maximum)  Min: $($stats.Minimum)"

$marks += 95
"After adding 95, count is $($marks.Count)"
output
First: 78  Last: 71  Count: 5
Sum by loop: 394
Sum: 394  Average: 78.8  Max: 92  Min: 65
After adding 95, count is 6

Index 0 is the first item and -1 is the last. += makes a new, longer array.

Task 2

Student totals with a calculated property

powershell · totals.ps1
$students = Import-Csv datasets/students.csv |
    Select-Object Name, Class,
        @{ Name = 'Total'; Expression = { [int]$_.Maths + [int]$_.Science + [int]$_.English } } |
    Sort-Object Total -Descending

Task 3

A hashtable of item → price

powershell · prices.ps1
$price = @{}
foreach ($row in Import-Csv datasets/inventory.csv) {
    $price[$row.Item] = [int]$row.Price
}

$price.Count
$price['Laptop']
$price.Mouse
output
8
58000
400

A key with a space needs brackets: $price['USB Cable'] gives 150.

Task 4

Look up items

Add this to prices.ps1. Check the key exists before you use it.

powershell · prices.ps1 (continued)
$item = Read-Host "Item name"
if ($price.ContainsKey($item)) {
    "$item costs Rs. $($price[$item])"
} else {
    "Sorry, '$item' is not in the list."
}

# price of a small shopping cart
$cart  = 'Mouse', 'Keyboard', 'Webcam'
$total = 0
foreach ($c in $cart) { $total += $price[$c] }
"Cart total: Rs. $total"
output · two runs
Item name: keyboard
keyboard costs Rs. 750
Cart total: Rs. 3350

Item name: Tablet
Sorry, 'Tablet' is not in the list.
Cart total: Rs. 3350

Hashtable keys ignore case, so keyboard finds Keyboard.

Task 5

Low-stock report

List every item with fewer than 10 in stock, and save it.

powershell · lowstock.ps1
$report = foreach ($row in Import-Csv datasets/inventory.csv) {
    $qty = [int]$row.Qty
    if ($qty -lt 10) {
        if ($qty -eq 0) { $status = 'OUT OF STOCK' } else { $status = 'Low' }
        [pscustomobject]@{ Item = $row.Item; Qty = $qty; Status = $status }
    }
}

$report
$report | Export-Csv low-stock.csv -NoTypeInformation
output
Item      Qty Status
----      --- ------
Monitor     8 Low
Laptop      5 Low
USB Cable   0 OUT OF STOCK
Printer     3 Low
Router      0 OUT OF STOCK

[pscustomobject]@{ ... } turns a hashtable into an object with those properties, ready for a table or a CSV.

Viva questions

What is the difference between an array and a hashtable?

An array is an ordered list read by position ($a[0]). A hashtable stores key-value pairs read by key ($h['Laptop']).

How do you create an empty array and an empty hashtable?

$a = @() and $h = @{}.

Why use ContainsKey()?

Reading a missing key gives $null silently. ContainsKey() lets you tell the user the item does not exist.

What does [ordered]@{} do?

It makes a hashtable that keeps keys in the order you added them. A normal hashtable may print them in any order.
