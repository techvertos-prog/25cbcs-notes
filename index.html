How to use this wiki

  1. Read the command tutorials first if awk or jq are new to you. Each lab links back to the commands it uses.
  2. Open a terminal in this folder. Every example reads from datasets/, so you can paste commands and get the same output shown on the page.
  3. Work through the lab's three use cases. Each one is a complete, runnable script, followed by its expected output.
  4. Finish with the viva / exam questions at the bottom of every lab.

cd CBCS-UNIT4-STUDY-GUIDE
# top 3 client IPs in the sample web log

     14 192.168.1.15
     13 10.0.0.5
Linux vs macOSThe labs target Linux with GNU tools. On macOS, sed -i, date -d and a few awk functions behave differently; the pages flag these where they matter. Install gnu-sed, gawk and coreutils with Homebrew to match the outputs exactly.
